# หน่วยซื้อพื้นที่: ตารางหลา/ตารางฟุต → ตารางเมตร

เพิ่มทะเบียนหน่วย `ตร.หลา` และ `ตร.ฟุต` และวิธีแปลง `AREA_UNIT` ในระบบ local เดิม ไม่เพิ่มตารางฐานข้อมูล ไม่เพิ่มรายการวัสดุตัวอย่างลงคลังจริง และไม่แก้ราคา/หน่วยของวัสดุหรือโครงการเดิม

อัตราพื้นที่ตาม [NIST Handbook 44 Appendix C](https://www.nist.gov/system/files/documents/2021/11/30/2022-HB44-Section-Appendix-C.pdf):

| หน่วยซื้อ 1 หน่วย | ปริมาณที่ได้เป็นหน่วยใช้ |
|---|---:|
| ตร.หลา | 0.83612736 ตร.ม. |
| ตร.ฟุต | 0.09290304 ตร.ม. |

เปิดคลัง → เพิ่มรายการ → เลือกหน่วยซื้อเป็น ตร.หลา หรือ ตร.ฟุต ระบบเลือกหน่วยใช้ ตร.ม. และวิธีแปลงพื้นที่ให้ แล้วกรอกราคาต่อหน่วยซื้อ แสดงอัตราแปลง/ราคาต่อ ตร.ม. ทันที ไม่ต้องกรอกกว้าง/ยาวหรือตัวคูณเอง เช่น 900 บาท/ตร.หลา ÷ 0.83612736 = 1,076.39104167 บาท/ตร.ม. (แสดงไม่เกิน 8 ตำแหน่ง ใช้ค่าจริงก่อนปัดตามแกนเดิม)

หากเลือกวิธี AREA_UNIT ด้วยตนเอง ต้องเลือกหน่วยซื้อคู่ที่รองรับ ระบบตรวจฝั่ง server อีกชั้นและปฏิเสธหน่วยใช้ที่ผิดมิติ วิธี DIRECT/COUNT/COUNT_LENGTH/AREA/VOLUME เดิมคงความหมายเดิม หากวัสดุใช้ในงานแล้วและจะเปลี่ยนหน่วย ต้องเพิ่มรหัสวัสดุใหม่ตามกฎ snapshot เดิม

Excel local v3 ใช้คอลัมน์เดิม: conversion_method=AREA_UNIT, purchase_unit_code=ตร.หลา หรือ ตร.ฟุต, usage_unit_code=ตร.ม. อัตรามาตรฐานคำนวณใหม่โดยระบบ ไม่เพิ่มช่องแก้ factor ไฟล์เก่ายังอ่านได้ สำรอง/กู้คืนเก็บหน่วยและวิธีแปลงได้ และเติมทะเบียนหน่วยสองตัวที่ยังไม่มีโดยไม่เขียนทับหน่วยเดิม ไม่ใช่การอนุมัติ importer ออนไลน์
