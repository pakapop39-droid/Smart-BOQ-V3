# ปริมาณใช้ต่อหนึ่งหน่วยขายและการแปลงต้นทุนทันที

วันที่ 24 ตุลาคม 2569 · Local · Risk T2 · ใช้ API/schema/สูตรเดิม

## อนุมัติ
Scope + Implementation โดยคุณต๋องจากคำขอให้เปลี่ยนชื่อช่องเป็น “ปริมาณใช้ต่อ 1 หน่วยขาย” แสดงหน่วยและการแปลงราคาต่อมัดเป็นต่อเมตรพร้อมต้นทุนทันที Environment Local; migration No; production No; ไม่เชื่อมออนไลน์หรือ push GitHub

## ขอบเขต
- เปลี่ยนชื่อช่องปริมาณเฉพาะต้นทุนในคลังรายการทำราคาต่อหน่วย ไม่เปลี่ยนความหมาย TOTAL ของโครงการเดิม
- ระบุหน่วยใช้ของวัสดุและหน่วยขายของรายการคลัง เช่น ไม้โครง8เมตร ต่อผนัง1ตร.ม.
- แสดงตัวแปลงหน่วยซื้อ/หน่วยใช้ ราคาต่อหน่วยใช้ และต้นทุนบรรทัดต่อ1หน่วยขายทันทีระหว่างกรอก โดยเรียกแกน calculateLive เดิม ไม่สร้างสูตรเงินอีกชุด
- ตัวอย่าง: ราคา290บาทต่อมัด, 1มัดใช้ได้25เมตร → 11.60บาทต่อเมตร ×8เมตร → ต้นทุน92.80บาทต่อผนัง1ตร.ม. เป็นตัวอย่างการอ่าน ไม่รับรองอัตราหน้างาน
- คำนึงถึงตัวหาร เผื่อเศษ และแหล่งปริมาณจากกลุ่มตามกฎเดิม ไม่เอาตัวตั้งดิบไปอ้างเป็นปริมาณจริงเสมอ
- แก้รายการเดิมใช้หน่วย/yieldจาก snapshot เดิม ราคาตามช่องกรอก ไม่ดึงราคาคลังใหม่ย้อนหลังเงียบ ๆ
- กรอกไม่ครบ ผิดรูปแบบ ตัวหารศูนย์ หรือข้อมูลแปลงหน่วยขาด ต้องบอกว่ารอข้อมูล ไม่แสดงศูนย์แทน ค่าศูนย์ที่กรอกจริงใช้ตามกฎเดิม
- แสดงเฉพาะต้นทุนบรรทัด ไม่เรียกว่ายอดทั้งงาน/ราคาขายทั้งหมด ยังไม่บันทึกจนกดบันทึก
