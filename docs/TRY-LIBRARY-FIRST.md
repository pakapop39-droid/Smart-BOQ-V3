# ทดลองคิดราคาจากคลังก่อนเลือกเข้า Keyplan

เปิด http://127.0.0.1:5177/ แล้วรีเฟรชหน้า ใช้แอปหลักในเครื่อง ยังไม่เชื่อมออนไลน์

## เตรียมราคาต่อหน่วยในคลัง
1. เปิดเมนู **คลังรายการทำราคา** สร้างรายการ เช่น “ผนังกรุลามิเนต SAMPLE” เลือกหมวด หน่วยขาย ตร.ม. และกำไร
2. ภายในรายการนี้ เตรียมกลุ่มวัตถุดิบต้นทุนถ้าต้องแบ่งกลุ่ม หรือลงต้นทุนตรงถ้าไม่ต้องแบ่ง ไม่ต้องสร้างกลุ่มสำหรับทุกงาน
3. เลือกวัสดุและค่าแรงจากคลัง กรอกอัตราที่ใช้ต่อ **1 หน่วยขาย** ราคาซื้อกับหน่วยใช้ยังเป็นคนละหน่วยได้ ค่าแรงต้องเลือกประเภทตามงาน อย่าเดาขอบเขตหรือสูตรจริงจากตัวอย่าง
   ช่อง “ปริมาณใช้ต่อ 1 หน่วยขาย” ใช้หน่วยใช้ของวัสดุ เช่น8เมตรต่อผนัง1ตร.ม. ด้านล่างแสดงราคาต่อมัด→ราคาต่อเมตร→ต้นทุนบรรทัดให้ทันทีระหว่างกรอก ตรวจตัวหาร/เผื่อเศษและฐานกลุ่มด้วย ก่อนกดบันทึกยังไม่เขียนข้อมูล
4. บันทึกแล้วตรวจต้นทุนต่อหน่วยและราคาขายต่อหน่วยล่าสุด ถ้าขาดข้อมูลให้กรอกให้ครบ เมื่อพร้อมทดลองจึงตั้งรายการเป็น **พร้อมใช้** ในเครื่อง สถานะนี้ยังไม่ใช่การรับรองราคาจริง

## เลือกราคาเข้า Keyplan
1. สร้าง/เปิดโครงการ → ห้อง → Keyplan ตามแบบ เช่น B01 เคาน์เตอร์ครัว
2. ใช้คำสั่ง **เลือกรายการราคาขายจากคลัง** ค้นหารายการพร้อมใช้ ตรวจชื่อ สเปก รุ่น หน่วย และราคาต่อหน่วย
3. กรอกปริมาณจริง เช่น ตู้เตี้ย3.50เมตร ท็อปหิน2.10ตร.ม. ผนัง6ตร.ม. ซิงก์1ชุด แยกเป็นรายการของตัวเอง ไม่เอาความยาวตู้ไปแทนพื้นที่หิน
4. ยืนยันเลือก ระบบเก็บต้นทุนและราคาเป็นสำเนาของโครงการ แล้วแสดงยอดตามปริมาณ หากยังไม่มีรายการพร้อมใช้ให้ไปเตรียมในคลัง แล้วกลับมาเลือกเข้า Keyplan เดิม
5. ทดลองเปลี่ยนปริมาณจริง ตรวจยอดใหม่และหน่วยขาย ระบบคำนวณจากอัตราต้นทาง ไม่คูณยอดเดิมซ้ำ ถ้าข้อมูลไม่ถูกต้องต้องแก้ก่อน ไม่แสดงศูนย์แทนข้อมูลที่ขาด

## ตรวจสำเนาราคาและงานเฉพาะ
เปิดรายละเอียดต้นทุนจากรายการใน Keyplan จะเห็นสำเนาที่เลือกมาเป็นอ่านอย่างเดียวก่อน ไม่ต้องประกอบกลุ่มใหม่อีกครั้ง

หากงานนั้นมีรายละเอียดเฉพาะจริง ให้กด **ปรับเฉพาะโครงการ** ก่อนแก้ต้นทุน/กลุ่ม/กำไร การแก้สำเนานี้ไม่เปลี่ยนคลังกลาง รายการเก่าที่เคยสร้างเองยังเปิดและใช้งานได้ผ่านทางรอง การบันทึกกลับเป็นต้นแบบต้องสั่งเองและได้รุ่นร่างให้ตรวจ

กลับไปแก้ราคาวัสดุหรือสร้างรุ่นใหม่ในคลัง แล้วกลับมาเปิดโครงการเดิมเพื่อตรวจว่าราคาเดิมยังคงอยู่ ไม่ปรับรุ่นโครงการให้อัตโนมัติ

## จุดที่ให้เจ้าของลอง
สร้างสูตรหลักในคลังได้เข้าใจหรือไม่ → เลือกเข้า Keyplan ง่ายหรือไม่ → หน่วยและปริมาณชัดหรือไม่ → เห็นยอดคำนวณทันหรือไม่ → แยกได้หรือไม่ว่ากำลังแก้คลังกลางหรือสำเนาโครงการ

ใช้ข้อมูล SAMPLE ในการทดลอง ยอดทดลองไม่ใช่ราคาหรือสูตรหน้างานที่รับรองแล้ว ข้อมูลเดิมและจำนวนตาราง24ยังคงอยู่ สำรองก่อนลองปรับงานที่ใช้อยู่ตาม TRY-STEP3.md
