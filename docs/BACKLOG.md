# Smart BOQ V3 — บัญชีงานตกค้าง
วันที่ 23 ตุลาคม 2569 · อ้าง MASTER 2.2 · งานค้างไม่ใช่การอนุมัติให้เชื่อมออนไลน์

## 1. ทำแล้วและไม่ต้องทำซ้ำ
บันทึกมาตรฐาน UX/UI 1.2 และภาพ/รายการตรวจรับ UX01–UX10 ใน UX-UI-ACCEPTANCE.md แล้ว AGENTS และสกิลอ้างเอกสารกลาง ไม่ต้องเสนอแบบ A หรือความหมายสำเนา/รุ่นใหม่ซ้ำ งานตรวจใช้งานจริงครบโครงการ หน้าอื่น และข้อมูลจริงยังคงค้างตามบัญชีนี้ ไม่ถูกปิดจากการล็อกดีไซน์
ทำสำเนาเป็นรายการราคาใหม่ได้จากเมนู ⋯ สร้างรหัสใหม่รุ่น 1 เป็นร่าง คัดลอกกลุ่ม/ต้นทุน/ของในชุด/ขอบเขตและ remap ความสัมพันธ์ ไม่เปลี่ยนคลังหรือต้นฉบับ ทดสอบรวม 191/191 และ build ผ่าน ดู RATE-CLONE-20261024.md
ตารางต้นทุนใช้เพิ่ม–ลบ–เลิกทำ ไม่มีสวิตช์เปิดใช้/ปิดใช้ในฟอร์มบรรทัด เลือกต้นทุนคิดเงินจริงที่แสดงได้ทุกแถว รองรับลบรายการเก่าที่เคยปิดไว้ เอา GL01 ออกเฉพาะ RT003 และเก็บในคลัง ทดสอบ 186/186 และ build ผ่าน ดู COST-LINES-ADD-DELETE-20261024.md
คำยืนยันล่าสุดคลังราคาขายแบบ A: เจ้าของรับรูปแบบจากตัวอย่างตู้เตี้ยแล้ว ใช้ในแอปหลักด้วยหน้าจอชุดเดียวกัน รายการ→ส่วนประกอบ→วัสดุ/ค่าแรง/ของในชุด เปิดตารางเต็มพื้นที่ทีละชั้น มีเส้นทางและย้อนกลับ ทดสอบ 184/184 และ build ผ่าน เก็บข้อมูลเดิมและไม่ย้ายตัวอย่างเข้าแอปหลัก ดู UI-RATE-A-MAIN-ACCEPTED-20261024.md ยังต้องทดลองงานจริงครบโครงการและตรวจข้อมูลราคา
รอบ UX/UI คลังวัสดุ/ค่าแรง/VS Modular ใช้ตารางหลัก/แผงขวาแล้ว คงแท็ก/bulk/undo/Excel ทดสอบ 180/180 และ build ผ่าน ดู [ผลส่งทดลอง](UI-CATALOG-WORKSPACE-20261024.md) รอเจ้าของรับรูปแบบ หน้าโครงการและหน้าอื่นยังไม่ปรับครบตามดีไซน์
รอบ UX/UI คลังรายการทำราคา: ตารางหลัก/แผงขวา คำนวณร่างทันที ค้นหา/กรอง ลบต้นทุนหลายแถวและเลิกทำ พัฒนาในเครื่องแล้ว ทดสอบ 175/175 และ build ผ่าน รอเจ้าของทดลองรับรูปแบบ ดู [บันทึกส่งทดลอง](UI-RATE-WORKSPACE-20261024.md) หน้าอื่นยังไม่ปรับครบตามกติกาดีไซน์

เส้นทางหลักปัจจุบัน: จัดต้นทุน/กำไร/ราคาต่อหน่วยในคลังรายการทำราคา → เลือกเข้า Keyplan → กรอกปริมาณจริง; รายละเอียดโครงการเป็นอ่านอย่างเดียวก่อน ปรับเฉพาะงานเป็นทางรอง ไม่ย้าย/ลบงานเก่า ดู LIBRARY-FIRST-20261024.md
มี SQLite 24 ตาราง คลังทำราคาต่อหน่วย/รุ่น READY→สำเนาโครงการ บันทึกจากโครงการเป็น DRAFT รหัส RT อัตโนมัติ แผง/ชุด BUY/MAKE แยกกลุ่ม คง snapshot ของในชุดไม่คิดซ้ำ สรุปซื้อข้าม Keyplan Excel คลังและ backup ในเครื่อง มีชุดทดสอบล่าสุด 183 cases ผลนี้ไม่ปิดงานต่อไปนี้

## 2. บัญชีตรวจงาน local

L01–L06 พัฒนาในเครื่องรอบขั้นที่ 3 แล้ว พร้อมการตรวจอิสระและทดสอบ; รอเจ้าของทดลองรูปแบบจริงตาม TRY-STEP3 ก่อนปิดรับงาน รายละเอียดด้านล่างเก็บเกณฑ์เดิมสำหรับตรวจย้อนกลับ ไม่หมายความว่ายังไม่มีโค้ดทุกข้อ
| รหัส | งานค้าง/ข้อเท็จจริง | ผลส่งมอบและเกณฑ์จบ |
|---|---|---|
| L01 | ทำแล้ว: ทะเบียน UUID และ links ใน SQLite พร้อม preview ย้ายข้อความเดิม | ทำทะเบียน/ผูกหลายแท็ก ย้ายข้อความเดิมโดย preview ไม่ลบ ไม่เดาจากชื่อสินค้า เพิ่ม/แก้ชื่อ/รวม/ลบเฉพาะแท็ก ใช้ข้ามสามคลังได้ |
| L02 | ทำแล้ว: ค้นหา/OR filter/เลือกหลายแถวและ bulk tags/export ในหน้าหลัก | แยกมุมมองวัสดุ/ค่าแรง/VS Modular แสดงจำนวน เลือกทั้งหมดเฉพาะที่เห็น เปลี่ยน filter ล้าง selection เพิ่ม/เอาแท็กออกหลายรายการ/ส่งออกที่เลือก |
| L03 | ทำแล้ว: เลือกเข้าต้นทุน/ลบหลายแถว พร้อมคืนทั้งชุดและคำนวณเดิม | picker ค้นหา/กรอง/ติ๊กหลายรายการ เพิ่มอย่าง atomic; ลบหลายแถวพร้อมคืนทั้งชุดและ snapshot; รหัสที่เพิ่มแล้วไม่สร้างซ้ำโดยไม่ได้ตั้งใจ |

| L05 | ทำแล้ว: ส่งออกแม่แบบ 3 (แท็ก/ส่วนประกอบชุด/Modular metadata) อ่านรุ่น 1/2 โดยคงช่องที่ไม่มี | เทียบ export→import ทุกช่อง รวม tag rename/merge, IDs/version, missing row, no-op, conflict, unknown tag preview และการเก็บ snapshot; ไม่อ้างว่ารวมของในชุดครบเพราะมีชีต VS |
| L06 | ทำแล้ว: backup24 รวมแท็ก/journal ตรวจ restore18/22/24 พร้อม preview และ backup ก่อนเปลี่ยน | ออกแบบรุ่น backup ใหม่เมื่อเปลี่ยน schema, รับไฟล์เก่า, backup ก่อนย้าย/restore และตรวจยอดเดิม; ห้ามเปลี่ยนตัวตนหรือ sync คลังไปโครงการ |
| L07 | เปลี่ยนต้นแบบที่โครงการเดิมใช้อยู่แบบเปรียบเทียบยังไม่มี | preview รุ่นเก่า→ใหม่ แสดงหน่วย/ปริมาณ/รายการปรับเฉพาะ/ราคา/ขอบเขตก่อนยืนยัน ไม่เปลี่ยนเงียบและไม่อัปเดตอัตโนมัติ |
| L08 | ข้อมูลรายช่องตามสัญญาเดิมยังไม่เท่ากับฟอร์ม local ทั้งหมด | ทำ field mapping จาก DATA-REQUIREMENTS ไป schema/form จริง กำหนด implemented/pending/alias/retired อย่างมีเหตุผล รวมบริษัท/ผู้จัดทำ/หน่วย/ราคา/สถานะ ไม่ถือการจัดเอกสารนี้เป็นการลดข้อบังคับ |

## 4. งานภายหลัง — ยังไม่อนุมัติให้ดำเนินการออนไลน์
| รหัส | งาน | เกณฑ์ก่อนเปิดใช้ |
|---|---|---|
| O01 | นำแบบปัจจุบันไป Vercel/InsForge | อนุมัติแยก ออกแบบ schema ตามรุ่น local ที่ตรวจรับ ห้ามคัดลอกฐานทดลองทั้งก้อน |
| O02 | Auth บริษัท 1:1 / RLS / ownership | ทดสอบบริษัท A/B, anonymous, direct DML, RPC, ข้อมูลลูกและ backup โดยใช้ข้อมูลทดสอบ |
| O03 | VERIFIED/CONFIRMED/LOCKED ที่ server | บังคับทุกเส้นทาง API/ตารางลูก การคัดลอกเป็นร่าง/version stale และป้องกันแก้ราคาย้อนหลัง |
| O04 | ตรวจความปลอดภัย/transaction/performance บนระบบจริง | ปิดข้อเตือน advisor เดิมที่ค้างด้วยหลักฐานใหม่ ไม่ใช้ local tests แทนการตรวจ server |
| O05 | ย้ายเฉพาะข้อมูลที่อนุมัติ/สำรอง/rollback | ไม่ย้ายขยะทดลองหรือข้อมูลจริงโดยไม่มีบัญชีรายการและการยืนยัน |

ใบเสนอราคาลูกค้าสมบูรณ์ การคิดภาษี ส่วนลด สต็อก PO และสมาชิกเป็นนอก MVP ไม่ใช่งานที่ต้องแอบเติมเพื่อปิดบัญชีนี้

## 5. วิธีปิดงาน
แต่ละรายการต้องมี source/เอกสารที่แก้ กรณีทดสอบและผลจริง ข้อจำกัด และจุดตรวจร่วมกับเจ้าของ ไม่ใช้จำนวน tests รวมเพียงอย่างเดียวปิดงาน ไม่มีการถือคำว่า READY ของข้อมูล SAMPLE ว่า “ตรวจแล้ว/ใช้ราคาจริงได้”
