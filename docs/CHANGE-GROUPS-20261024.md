## กติกา
- component_groups และ rate_template_groups แสดงชื่อ “กลุ่มวัตถุดิบต้นทุน” เหมือนกัน กรอกชื่อพร้อมรายละเอียดประเภท/วิธีจัดหา/ปริมาณตามเดิม ไม่สร้างหมวดวัสดุชุดใหม่
- ระบบสร้าง G001, G002… ภายในรายการทำราคาหรือต้นแบบแต่ละรายการเมื่อบันทึก ไม่ต้องจำหรือกรอกรหัส
- กลุ่มที่มีอยู่คงรหัสเดิม เปลี่ยนชื่อแล้วไม่เปลี่ยนรหัส UUID/FK ยังคงเดิม
- จำลำดับบนเจ้าของ group_code_sequence และตรวจรหัส G เดิมรวมรายการหยุดใช้ ไม่ใช้รหัสที่ลบแล้วซ้ำ ไม่รับรหัสใหม่จาก client แทนตัวสร้าง
- กำหนดลำดับใน transaction เดียวกับบันทึก ล้มเหลวแล้วไม่เสียเลข/ไม่บันทึกบางส่วน ร่างต้นแบบเท่านั้นที่เพิ่มกลุ่มได้ตามกฎเดิม
- ไม่เปลี่ยนสูตร พื้นที่ BUY/MAKE ราคาต้นทุน snapshot หรือข้อมูลโครงการเดิม ไม่เชื่อมออนไลน์หรือ push GitHub
