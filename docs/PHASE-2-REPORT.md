## แกนคำนวณที่ทำแล้ว

| ฟังก์ชัน | หน้าที่ |

| boq_yield | แปลงหน่วย DIRECT / COUNT / COUNT_LENGTH / AREA / VOLUME |

## Excel ที่ทำแล้ว

- ตัวอ่าน/เขียน .xlsx ใน lib/catalog-excel.mjs มีชีตวัสดุ ค่าแรง และ VS Modular
- รักษารหัส เลขศูนย์นำหน้า ทศนิยมและ version เป็นข้อความ ปฏิเสธสูตร/macros/ลิงก์ภายนอกและไฟล์เกินขีดจำกัด
- boq_catalog_export / boq_catalog_preview / boq_catalog_commit รองรับเพิ่ม แก้ ไม่เปลี่ยน ผิด ขัดแย้ง ตรวจ ID/company/version และ unique canonical code
- ตรวจรายการก่อนยืนยัน บันทึกทั้งชุดใน transaction ล็อกแถวบริษัทเพื่อเรียงงานแก้คลัง ไม่ทับข้อมูลใหม่จากไฟล์เก่า
- นำซ้ำไม่เพิ่มแถวหรือ version ซ้ำ รองรับส่งคำสั่งซ้ำหลังการตอบกลับขาดหาย ถ้าข้อมูลปัจจุบันตรงทั้งหมด
- รายการที่หายจาก Excel ไม่ถูกลบ ราคาอยู่ที่ cost_resources แห่งเดียว รายละเอียดโมดูลาร์ใช้ resource_id และรุ่นข้อมูลของแม่
- ยังไม่มีหน้าจอเลือกไฟล์/ตรวจรายการ/กดยืนยัน ต้องเชื่อมในเฟสหน้าบ้าน

ทดสอบ SDK ไป endpoint จริงโดยไม่เข้าสู่ระบบ: อ่านคลัง ส่งออก เรียก helper ภายใน และเรียก test harness ถูกปฏิเสธทั้งหมด ยังไม่ใช่หลักฐานว่าทดสอบ session ผู้ใช้จริงสองบริษัทครบแล้ว

### ผลสแกนสิทธิ์ที่ต้องอ่านประกอบ

ผล InsForge Advisor ล่าสุดอยู่ใน artifacts/advisor.json หลังลด SECURITY DEFINER ของฟังก์ชันอ่านและเติมดัชนี FK แล้ว ยังแจ้ง critical 2 รายการที่ boq_catalog_preview และ boq_catalog_commit เพราะเป็น SECURITY DEFINER ที่บัญชีผู้ใช้เรียกได้ ทั้งคู่เป็นทางเข้าที่ตั้งใจให้บันทึกแบบ transaction โดยผูกบริษัทจาก auth.uid() ไม่รับบริษัทจากไฟล์ และ helper ที่รับ tenant โดยตรงไม่เปิดให้ผู้ใช้เรียก ยังไม่ปิดหรือซ่อนคำเตือนเหล่านี้ ต้องทดสอบผ่าน token ผู้ใช้จริงก่อนเปิดหน้าจอนำเข้าให้ใช้งานจริง

warning อีก 5 รายการ: ตารางอ้างอิงกลาง units/cost_types/cost_groups อ่านได้ทุกบัญชีที่เข้าสู่ระบบตามแบบ (เขียนตรงไม่ได้) และคำแนะนำดัชนี is_active ของบริษัท/สมาชิก 1:1 ยังไม่เพิ่มดัชนี boolean โดยไม่มีหลักฐานประสิทธิภาพ กฎ slow-query ของตัวสแกนทำงานไม่สำเร็จ จึงไม่อ้างว่าผ่านการตรวจความเร็วจาก Advisor

ผล npm audit ของ dependency ที่ใช้ ณ วันตรวจไม่พบช่องโหว่ที่รายงานมา ข้อนี้ไม่แทนการทดสอบสิทธิ์หรือการตรวจ production

## สิ่งที่ยังไม่ได้ทำและจุดรอข้อมูล

- ยังไม่สร้างหรือ deploy หน้าบ้าน Vercel ระบบล็อก/คัดลอก/ยืนยัน coverage เต็มชุดเป็นงานช่วงถัดไป ไม่เปิดให้ข้ามการตรวจ
- ยังไม่ทดสอบผ่านหน้าบ้านด้วยบัญชีจริง การทำงานหลายเครื่องพร้อมกัน และความเร็ว 20 Keyplans × 5–6 งานย่อย
- D03 ขอบเขตราคาผลิตเอง, D04 เผื่อเศษจริง, D05 ขนส่ง/ต้นทุนร่วม, D09 เงื่อนไขราคาซื้อ และ Index V01–V04 ยังต้องถามก่อนพัฒนาส่วนที่อาศัยข้อมูลจริง ไม่เติมกติกาแทน
- ยังไม่ย้ายบัญชี บริษัท คลังจริง หรือข้อมูลโครงการ และยังไม่สร้างฐาน production
- ไม่มีการเปลี่ยน deployment/การเชื่อมต่อ/ข้อมูลระบบเดิม

ฟังก์ชันทดสอบในฐานเป็นเครื่องมือของระบบทดลอง ปิดสิทธิ์ PUBLIC/anon/authenticated ไม่เผยแพร่ให้ผู้ใช้ และไม่ย้ายไปฐาน production ในภายหลัง
