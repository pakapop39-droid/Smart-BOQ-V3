# ทำสำเนาเป็นรายการราคาใหม่

เปิดแอปหลัก http://127.0.0.1:5177/#rates → เปิดต้นแบบ → **⋯ → ทำสำเนาเป็นรายการราคาใหม่** → ตั้งชื่อ → **สร้างสำเนาร่าง** ระบบสร้าง RT รหัสใหม่ รุ่น 1 สถานะ DRAFT แล้วเปิดตารางส่วนประกอบของสำเนาทันที

สำเนาคงหน่วยขาย กำไร อัตราใช้ เผื่อเศษ หมายเหตุ กลุ่มและทุกวิธีจัดหา วัสดุ/ค่าแรง snapshot ราคา ของในชุด รายละเอียดรวม/ไม่รวม ขอบเขต และความสัมพันธ์บรรทัดที่เพิ่มนอกชุด เปลี่ยนตัวระบุภายในของกลุ่ม/บรรทัด/ขอบเขตทั้งหมดให้อยู่ใต้สำเนา ไม่เพิ่มวัสดุในคลัง ไม่รวมประวัติเลิกทำของต้นฉบับ ไม่ใช้ยอด READY ที่เก็บเก่ามาเป็นยอดรับรองของสำเนา ต้องตรวจแล้วตั้งพร้อมใช้เอง

ใช้ได้จากต้นแบบร่างและพร้อมใช้ ต่างจาก **สร้างรุ่นถัดไป** ซึ่งใช้รหัสเดิม การทำสำเนาสร้างรหัสใหม่สำหรับอีกทางเลือก การแก้สำเนาไม่เปลี่ยนต้นฉบับหรือ snapshot ของโครงการเดิม สถานะข้อมูลรอกรอกยังคงรอกรอก ไม่สมมติปริมาณหรือราคาให้ครบ การยืนยันเพิ่มนอกชุดยังต้องผ่านกติกาตรวจขอบเขตเดิม

API local: POST /api/local/rate-clone รับ id, version ของต้นฉบับ และ name ใหม่ ตรวจบริษัท/รุ่น และคัดลอกใน transaction เดียว หากอ้างอิงเสียหรือชื่อไม่ครบ ย้อนกลับทั้งรายการและเลขลำดับรหัส ไม่มีตารางเพิ่ม เก็บ cloned_from_template_id ใน JSON ต้นแบบเพื่อระบุที่มา

ผลตรวจ: ทดสอบรวม 191/191 และ build ผ่าน เพิ่มกรณี READY พร้อมกลุ่ม/ของในชุด/ขอบเขต, remap origin_excluded_id และข้อมูลร่างไม่ครบ, rollback เมื่อรุ่นเก่า/ชื่อว่าง/ความสัมพันธ์เสีย ตรวจ UI บนฐานสำเนาแยกพอร์ต 5190 ทำสำเนา RT003 เป็น RT004 ร่าง 4 บรรทัด ต้นทุน 883.08 ขาย 1,471.80 เท่าก่อนแก้ และต้นแบบเดิมคงเดิม ไม่เพิ่มสำเนา QA ลงฐานหลัก

เฉพาะในเครื่อง ไม่เชื่อม InsForge ไม่ deploy และไม่ push GitHub หลักฐาน artifacts/rate-clone/ ไม่ส่งขึ้น Git
