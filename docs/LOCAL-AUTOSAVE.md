# บันทึกอัตโนมัติในเบราว์เซอร์ — Master 1.9

23 ตุลาคม 2569 · เฉพาะระบบทดลองในเครื่อง

## วิธีใช้

เปิดลิงก์เดิม http://127.0.0.1:5177/ ด้วยเบราว์เซอร์และโปรไฟล์เดิม ระบบบันทึกอัตโนมัติและแสดง “บันทึกในเบราว์เซอร์แล้ว” พร้อมเวลา ไม่ต้องกดบันทึก เปิดหน้าใหม่หรือรีเฟรชแล้วข้อมูลยังอยู่

เก็บแท็กและความสัมพันธ์ คลังทั้งสามประเภท รวมรายการที่ Import และรุ่นข้อมูล วิธีผลิต ปริมาณ กำไร พื้นที่ ราคาประจำโครงการ รายการต้นทุนทุกงาน และประวัติลบ/เลิกทำ ไม่เก็บผลรวมที่คำนวณไว้ แต่คำนวณใหม่จากข้อมูลต้นทางหลังเปิดหน้า

ช่องที่ยังกรอกไม่ครบหรือกรอกผิดก็เก็บค่าที่พิมพ์ไว้ ระบบยังแจ้งให้แก้ก่อนใช้ผลตามเดิม ไม่แปลงค่าที่ผิดเป็นศูนย์หรือคืนตัวอย่างเอง

## ปุ่มคืนค่า

- “คืนค่าตัวอย่างเฉพาะประมาณราคา” คืนปริมาณ/ราคาตัวอย่าง/รายการต้นทุนและประวัติการลบของงาน ส่วนแท็กและคลังที่ Import ยังอยู่ และบันทึกการคืนค่าทันที
- “คืนค่าตัวอย่างทั้งหมด” เปิดกล่องอธิบายผลก่อนยืนยัน ล้างเฉพาะร่างของแอปทดลองนี้ แล้วเปิดใหม่เป็นตัวอย่าง ไม่ล้างข้อมูลเว็บอื่นหรือฐานออนไลน์ กดยกเลิกแล้วข้อมูลไม่เปลี่ยน หากต้องเก็บคลังและแท็ก ให้ส่งออก Excel ก่อน

## ขอบเขตและกรณีผิดพลาด

ใช้ localStorage เฉพาะคีย์ smart-boq-new-test:local-draft:v1 รูปแบบมี schemaVersion 1 กับวันที่บันทึก ไม่มี credentials/token ในร่าง ไม่ส่งข้อมูลไปฐานออนไลน์ ผลคำนวณยังตรวจยอดกับ RPC เดิมได้เมื่อกดเอง

ถ้าอ่านร่างไม่ได้หรือเป็นรุ่นที่ไม่รองรับ ไม่เขียนทับข้อมูลเดิม แจ้งปัญหาให้เห็น หากพื้นที่เต็ม/เบราว์เซอร์ไม่ให้เก็บ จะแจ้ง “บันทึกไม่สำเร็จ” และค่าล่าสุดยังอยู่ในหน้า ไม่อ้างว่าเก็บแล้ว

ถ้าข้อมูลเปลี่ยนจากอีกแท็บ ให้หยุดการบันทึกในแท็บเก่าเพื่อไม่ทับข้อมูลล่าสุด มีปุ่มเปิดข้อมูลล่าสุดซึ่งโหลดหน้าใหม่ การเปลี่ยนเฉพาะหน้าที่เปิด/แถวที่ดูไม่ถือเป็นความขัดแย้ง การแก้ในแท็บที่หยุดบันทึกยังไม่ถูกเก็บ

การเก็บนี้ผูกกับเบราว์เซอร์ โปรไฟล์ และที่อยู่เว็บเดิม ไม่ซิงก์ข้ามเครื่องหรือ Chrome กับเบราว์เซอร์ในแอป หากล้างข้อมูลเว็บไซต์ ร่างนี้จะถูกล้างตามไปด้วย Excel ยังใช้สำรองคลังและแท็กได้ตามเดิม ไม่ได้สำรองทั้งโครงการ

## ผลตรวจ

- ทดสอบโมดูล: เก็บแล้วอ่านใหม่, เก็บค่าที่ยังไม่ครบ, ประวัติลบทั้งต้นทุนและแท็ก, ข้อมูลเสีย/รุ่นไม่รองรับ, พื้นที่เต็ม/สิทธิ์เก็บข้อมูล, ล้างเฉพาะคีย์แอป และตรวจความต่างระหว่างแท็บ
- เบราว์เซอร์: เพิ่มแท็กทดสอบ แก้ปริมาณเป็น 4.25 ลบ PN01 แล้วรีเฟรช ข้อมูลยังอยู่และกดเลิกทำหลังรีเฟรชได้ ปิดแท็บทดสอบแล้วเปิดแท็บใหม่ยังเห็นแท็กเดิม
- ยกเลิกกล่องคืนค่าทั้งหมดแล้วข้อมูลยังอยู่ การล้างคีย์สำเร็จและไม่กระทบคีย์อื่นตรวจด้วย storage จำลอง ไม่สั่งล้างข้อมูลผู้ใช้จริงเพื่อทดสอบ
- ไม่ทดสอบปิดโปรเซสเบราว์เซอร์ทั้งตัวหรือเปลี่ยนโปรไฟล์ผู้ใช้ เพราะจะกระทบหน้าต่างงานของผู้ใช้

ไม่มีการแก้ InsForge, migration, สิทธิ์, ระบบเดิม หรือ deploy Vercel ในรอบนี้
