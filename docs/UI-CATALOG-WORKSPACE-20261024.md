# Smart BOQ V3 — คลังวัสดุ ค่าแรง และ VS Modular แบบตาราง/แผงขวา

24 ตุลาคม 2569 · ทำในเครื่องตามคำอนุมัติล่าสุด · รอคุณต๋องทดลองรับรูปแบบ

## หน้าจอที่ปรับแล้ว

- แยกสามแท็บเดิม วัสดุ / ค่าแรง / VS Modular พร้อมจำนวน แถบบนมีค้นหา ปุ่มเพิ่ม และเมนู `⋯` รวมจัดการแท็ก นำเข้า/ส่งออก Excel และเลิกทำการลบแท็ก
- ตารางเป็นพื้นที่หลัก แสดงรหัส ชื่อ แท็ก หน่วยซื้อ/ใช้ ปริมาณที่ได้ต่อหน่วยซื้อ และราคาซื้อ หัวตารางคงที่ เลื่อนตารางได้เมื่อพื้นที่แคบ ไม่รวมยอดราคาต่างหน่วยเข้าด้วยกัน
- แถบแท็กงานพับได้ คง OR filter และค้นหาร่วมกัน หนึ่งทรัพยากรติดหลายแท็ก ไม่มีการสร้างวัสดุซ้ำหรือเพิ่มระดับเหนือ Keyplan
- คลิกแถวหรือปุ่มแก้เปิดแผงขวา ฟอร์มจัดหน่วยซื้อ/ใช้เป็นคู่ แสดงเฉพาะข้อมูลบรรจุที่เกี่ยวกับวิธีแปลง ประเภท ขอบเขต ขั้นซื้อ และหมายเหตุเปิดดูเพิ่มเติมได้ ไม่ตัด fields เดิมออก
- แผงแสดงการแปลงราคาขณะกรอก เช่น 300 บาท/มัด ÷ 25 เมตร/มัด = 12.00 บาท/เมตร ใช้ validation/yield และแกนคำนวณเดิม แยกค่าร่างออกจากราคาที่บันทึกแล้วในตาราง ราคาว่างเป็นรอข้อมูล ไม่แทนศูนย์
- ของในชุดและสเปก VS Modular อยู่ในแท็บภายในแผงขวา เพิ่ม/แก้รายละเอียดในแผงเดิม ไม่ต่อเป็นตารางยาวใต้คลัง บันทึกรายละเอียดย่อยแล้วกลับมาดูชุดเดิม
- เพิ่มจากแท็บค่าแรงตั้งประเภทค่าแรง/บริการให้เป็นค่าเริ่มต้นที่แก้ได้ เพิ่ม VS Modular สร้างรายการหลักก่อน แล้วเปิดกรอกสเปกต่อ จึงแสดงในแท็บ VS Modular ตามการจำแนกเดิม ถ้าหยุดหลังบันทึกหลักแต่ยังไม่เพิ่มสเปก รายการอยู่ในคลังวัสดุ ไม่สร้างรายการใหม่ซ้ำ
- ก่อนออกจากค่าค้างมีบันทึก/ทิ้ง/อยู่ต่อ มีป้องกันรีเฟรชทำค่าค้างหาย เปิด/ปิดแผงคงคำค้น ตัวกรอง และตำแหน่งเลื่อนตาราง

## ฟังก์ชันเดิมที่คงไว้

เลือกทั้งหมดเฉพาะผลที่แสดง เปลี่ยนแท็บ/เงื่อนไขกรองแล้วล้างการเลือก แถบจัดการหลายรายการแสดงเมื่อติ๊กเลือกเท่านั้น เลือกแท็กเป็นช่องติ๊กแทนการกด Ctrl ในกล่องหลายตัวเลือก มีเพิ่มแท็ก เอาแท็กออก ส่งออก Excel ที่เลือก และยกเลิกการเลือก ไม่เพิ่มแก้ราคา/หน่วยพร้อมกันทั้งชุด

จัดการเพิ่ม เปลี่ยนชื่อ รวม ลบแท็ก และเลิกทำการลบ ใช้ API และทะเบียน/undo เดิม ลบแท็กไม่ลบทรัพยากร เลิกทำนี้ไม่ใช่ย้อนการรวมแท็กหรือย้อนการเพิ่ม/แก้ราคาวัสดุ การจัดการต้นทุน/เลิกทำในโครงการและคลังรายการทำราคาคงอยู่ตามขอบเขตเดิม

นำเข้า/ส่งออก Excel รุ่น 3 ใช้สัญญาเดิม รวมรหัส รุ่นข้อมูล แท็ก ของในชุด และ Modular; ยังรับรุ่นเก่าตามเดิม มี preview ก่อนยืนยัน ไม่อัปเดต snapshot โครงการตามราคาคลังเอง

## ขอบเขตการเปลี่ยนและผลตรวจ

ปรับ `web/local-library.mjs` ใช้ drawer ร่วมกับคลังรายการทำราคา เพิ่ม `web/local-catalog-editor.mjs` และ local `/catalog-draft-preview` ผ่าน `local/catalog-draft.mjs` ซึ่ง save ภายใน savepoint แล้ว rollback ทุกครั้ง จึงใช้ validation เดิมตรวจร่างโดยไม่เพิ่ม/แก้ข้อมูลจริง ไม่เพิ่มตาราง ไม่แก้สูตรใน live-calculator/group-quantity และไม่เชื่อมออนไลน์

- ชุดทดสอบ 180/180 และ build ผ่าน เพิ่ม 5 กรณีสำหรับร่างราคา/ข้อมูลบรรจุ หน่วยซื้อหลายวิธี ราคาไม่ครบ/ศูนย์ที่ระบุเอง ข้อมูล stale/เปลี่ยนสเปกที่ใช้แล้ว และ snapshot ไม่เปลี่ยน
- ตรวจ UI บนฐานสำเนาแยกพอร์ต 5188: เปิดแก้ทั้งสามคลัง ติดแท็กวัสดุ 3 ค่าแรง 2 และ Modular 1 รายการ ลบแท็ก/รีเฟรช/เลิกทำ คืนความสัมพันธ์ทั้ง 6 รายการ
- ส่งออก Excel ที่เลือกจริงได้ 3 รหัส PLY01/PLY02/PLY-LOCAL-01 พร้อมแท็กและรหัสภายในไม่ซ้ำ ตรวจการเพิ่ม VS Modular หลัก→สเปก→กลับชุดเดิม และการปิดแผงคง scrollTop 166 ตามเดิม
- ตรวจภาพเดสก์ท็อปและพื้นที่ CSS ประมาณ 1367×768 ตารางเลื่อนแนวนอนได้เมื่อเปิดแผง ผลทดสอบและภาพอยู่ใน artifacts/catalog-workspace-20261024 (ไม่ส่ง Git)
- เทียบ state ฐานหลักตรงก่อนเริ่มงานทั้งหมด แกนคำนวณสองไฟล์ hash ตรงเดิม ราคาของทรัพยากรเดิมในฐาน QA และผลคำนวณทั้ง 4 โครงการตรงฐานหลัก ข้อมูล/แท็ก/รายการ QA ใหม่อยู่ในฐานสำเนาเท่านั้น

ยังไม่ใช่การรับรองราคาจริงหรือรับรูปแบบโดยเจ้าของ ไม่ได้ปรับทุกหน้าของแอป ไม่มีการ deploy หรือ push GitHub

## วิธีทดลอง

1. เปิด http://127.0.0.1:5177/#catalog และรีเฟรช เลือกวัสดุ ค่าแรง หรือ VS Modular
2. ค้นหา/กรองแท็ก แล้วคลิกรหัสหรือแถวเพื่อเปิดแก้ด้านขวา กรอกแล้วดูราคาแปลง กดบันทึกจึงเก็บ หรือปิดแล้วทิ้งการแก้ไข
3. ติ๊กหลายรายการ แถบคำสั่งจะปรากฏ เลือกเพิ่ม/เอาแท็กออกเป็นช่องติ๊ก หรือส่งออก Excel ที่เลือก
4. เมนู `⋯` มีจัดการแท็ก นำเข้า/ส่งออก และเลิกทำการลบแท็กล่าสุด
5. รายการชุดมีปุ่ม “ของในชุด / สเปก” เพื่อเปิดแท็บย่อยในแผงขวา โครงการเดิมยังใช้ snapshot เดิม
