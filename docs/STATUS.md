# สถานะ Smart BOQ V3 — ขั้นที่ 3 ในเครื่อง

อ้าง MASTER 2.2 · ปรับปรุง 24 ตุลาคม 2569

รอบเก็บงาน GitHub: เจ้าของอนุมัติให้อัป source และเอกสารล่าสุดขึ้น pakapop39-droid/Smart-BOQ-V3 โดยไม่รวมฐาน ข้อมูลที่ทดลองบันทึก ไฟล์ผลทดสอบหรือ credentials และไม่เผยแพร่เว็บ ตรวจชุดไฟล์ก่อนส่งไม่พบไฟล์ต้องห้าม/ค่าลับ ทดสอบใหม่ 191/191 และ build ผ่าน รวมสกิลสำหรับ checkout นี้ที่ .codex/skills/smart-boq-ux-ui/ คำอนุมัตินี้ไม่ใช่การอนุมัติ deploy หรือเชื่อมฐานออนไลน์

ล่าสุดด้านเอกสาร: ล็อกกติกา UX/UI 1.2 ตามคำยืนยันเจ้าของ รวมแบบ A แผงแก้ไข เพิ่ม–ลบ–เลิกทำ ค้นหา หน่วยราคา คำนวณ/บันทึก และทำสำเนา อัปเดต MASTER/AGENTS/สกิลให้ชี้กติกากลาง พร้อมภาพถาวรและ checklist UX01–UX10 ใน [UX-UI-ACCEPTANCE](UX-UI-ACCEPTANCE.md) รอบนี้ไม่แก้โค้ดแอปหรือข้อมูล ไม่รันทดสอบแอปใหม่ ไม่เชื่อมออนไลน์ ผล 191/191 ด้านล่างเป็นประวัติรอบพัฒนาก่อนหน้า

ล่าสุด: เพิ่ม ⋯ → ทำสำเนาเป็นรายการราคาใหม่ ตั้งชื่อแล้วสร้างรหัสใหม่เป็น DRAFT รุ่น 1 คัดลอกส่วนประกอบทุกชั้นและความสัมพันธ์ของในชุด ไม่ซ้ำวัสดุ ไม่เปลี่ยนต้นฉบับ/โครงการเดิม ทดสอบรวม 191/191 และ build ผ่าน ตรวจ UI และ API บนฐานสำเนาแยก ดู RATE-CLONE-20261024.md ไม่เชื่อมออนไลน์

ล่าสุดการแสดงหน่วย: ตารางราคาต่อหน่วยแสดงซื้อเป็นปี๊บ/แผ่น/มัด อัตราบรรจุและราคาซื้อจาก snapshot หัวตารางแยกปริมาณใช้ต่อ 1 หน่วยขายจริง ต้นทุนบาทต่อหน่วยใช้ และต้นทุนต่อ 1 หน่วยขายจริง เช่น ตร.ม. ตรวจ GL01 ร่าง 1 ลิตรแสดง 200 บาท/ลิตรและ 200 บาท/ตร.ม. โดยไม่บันทึกทับปริมาณเดิม ทดสอบที่เกี่ยวข้อง 23/23 และ build ผ่าน หลักฐาน artifacts/unit-labels/ ไม่เปลี่ยนสูตรหรือเชื่อมออนไลน์

ล่าสุดช่องเลือกต้นทุน: เพิ่มค้นหารหัส/ชื่อเหนือ dropdown ในฟอร์มบรรทัดต้นทุน กรองพร้อมจำนวนที่พบ คงรายการที่เลือกเมื่อเปลี่ยนคำค้น ไม่บันทึกคำค้นเป็นข้อมูล ทดสอบรวม 188/188 และ build ผ่าน ตรวจในแอปหลักค้น “ลามิเนต” เหลือ 2 ตัวเลือก เลือก LM02 แล้วกรอก 1 ตร.ม. แสดงร่าง 1,203.91 / ขาย 2,006.52 จากสูตรเดิม ก่อนทิ้งการแก้ไข ไม่มีการบันทึกรายการทดลองหรือเชื่อมออนไลน์ หลักฐาน artifacts/resource-search/

ล่าสุดตารางต้นทุน: ใช้เพิ่ม–ลบ–เลิกทำ เอาสวิตช์เปิดใช้/ปิดใช้ออกจากฟอร์มบรรทัด เลือกต้นทุนคิดเงินจริงได้ทุกแถว ลบ GL01 เฉพาะ RT003 เก็บคลังและโครงการเดิมไว้ ทดสอบ 186/186 และ build ผ่าน ดู COST-LINES-ADD-DELETE-20261024.md

ล่าสุดด้านหน้าจอ: เจ้าของยืนยันแบบ A จากตัวอย่างตู้เตี้ยแล้ว ใช้หน้าจอชุดเดียวกันในแอปหลัก 5177 เปิดราคาขาย→ส่วนประกอบ→วัสดุ/ค่าแรงพร้อมเส้นทางและย้อนกลับ ตรวจข้อมูลเดิมและผลคำนวณทั้ง 4 โครงการคงเดิม ทดสอบ 184/184 และ build ผ่าน ไม่ย้าย SAMPLE จาก 5188 ไม่เชื่อมออนไลน์ ดู [ผลตรวจแบบ A ในแอปหลัก](UI-RATE-A-MAIN-ACCEPTED-20261024.md)

ล่าสุด: ฟอร์มต้นทุนคลังใช้ชื่อ “ปริมาณใช้ต่อ 1 หน่วยขาย” พร้อมหน่วยและการแปลงราคาซื้อเป็นราคาต่อหน่วยใช้/ต้นทุนบรรทัดทันทีระหว่างกรอก ใช้แกนเดิม ไม่บันทึกก่อนกดบันทึก ทดสอบ168/168และbuildผ่าน ดู RATE-LINE-PREVIEW-20261024.md

รอบเส้นทางคลัง: ใช้คลังรายการทำราคาเป็นจุดเตรียมต้นทุน/กำไร/ราคาขายต่อหน่วย แล้วเลือกเข้า Keyplan เพื่อกรอกปริมาณจริง เปิดต้นทุนโครงการเป็นอ่านอย่างเดียวก่อน มีปรับเฉพาะโครงการเป็นทางรอง ทดสอบ158/158และbuildผ่าน ตรวจหน้าจอครบและเทียบ4โครงการเดิมตรงก่อนเริ่ม ดู [วิธีทดลอง](TRY-LIBRARY-FIRST.md) และ LIBRARY-FIRST-20261024.md
