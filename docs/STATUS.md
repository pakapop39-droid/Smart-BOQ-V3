# สถานะ Smart BOQ V3 — หลังจัดมาสเตอร์ 2.0

วันที่ 23 ตุลาคม 2569 · เอกสารปัจจุบัน [MASTER.md](MASTER.md)

## สร้างจริงในเครื่อง

แอป SQLite 22 ตาราง มีคลังทำราคาต่อหน่วยและ snapshot โครงการ บันทึกงานกลับเป็นต้นแบบร่าง รหัส RT อัตโนมัติ คงสูตรเดิม มีรายงาน/Excel/backup ในเครื่อง โค้ดล่าสุดก่อนจัดเอกสารตรวจ 125/125 ผ่าน รายละเอียดหลักใน LOCAL-APP-22-GUIDE.md

## รอบนี้เปลี่ยนอะไร

รวมมาสเตอร์ 2.0 แยกประวัติเดิมแบบเก็บต้นฉบับครบ ทำพจนานุกรมข้อมูลจริง/สัญญาข้อมูลเป้าหมาย บัญชีงานตกค้างและแผนแท็ก/เลิกทำ แก้คำสั่งโครงการและลิงก์เอกสารให้ชี้ฉบับปัจจุบัน ไม่แก้ source/schema/สูตร/SQLite ไม่ทดสอบฟังก์ชันแท็กใหม่เพราะยังไม่พัฒนา

## ยังไม่ครบ

ทะเบียนแท็ก/OR filter/bulk selection/persistent undo ในหน้าหลัก, ความครบของ Excel/backup ตาม schema ใหม่, ข้อมูลรายช่อง, การเปลี่ยนรุ่นเก่าแบบ preview, VERIFIED/LOCKED, benchmark และข้อมูลธุรกิจจริง ดู BACKLOG.md ครบทุกกลุ่ม

แผนเสนอ resource_tags/resource_tag_links อีก 2 ตาราง เป้าหมาย 24 เฉพาะเมื่ออนุมัติ ยังไม่สร้างจริง ยังไม่เชื่อม InsForge/deploy Vercel/ย้ายข้อมูลจริง

## GitHub

รอบเผยแพร่ก่อนหน้าอยู่บน main และตรวจ 121 tests ณ เวลานั้น ต่อมามี source และเอกสารแก้ในเครื่องเพิ่มเติม รอบเอกสารนี้ไม่ commit/push จึงไม่อ้างว่า GitHub ตรงกับสถานะในเครื่องทั้งหมด ไฟล์ฐาน credentials และ artifacts ไม่อยู่ใน repository
