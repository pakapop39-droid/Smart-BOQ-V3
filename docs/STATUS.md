# สถานะ Smart BOQ V3

ตรวจเพื่ออัป GitHub วันที่ 23 ตุลาคม 2569 หลังแชต “ตรวจสอบโฟลเดอร์ Smart BOQ New” ทำรอบพัฒนา 22 ตารางเสร็จ

## สถานะยืนยันแล้ว

แอปในเครื่องใช้ SQLite 22 ตาราง มีคลังรายการทำราคาต่อหนึ่งหน่วย 4 ตารางเพิ่มเติมจากฐาน 18 ตาราง เลือกรุ่นพร้อมใช้เข้า Keyplan แล้วกรอกปริมาณตามแบบได้ สำเนาต้นทุน กลุ่มงาน ขอบเขต รุ่น และราคาไว้ในโครงการ สูตรเดิมและการรวมซื้อข้าม Keyplan คงเดิม

อีกแชตตรวจบนหน้าจอด้วยต้นแบบขาย 5,000 บาท/ตร.ม. ปริมาณ 3 ตร.ม. ได้ 15,000 บาท เมื่อสร้างคลังรุ่นใหม่เป็น 6,000 บาท/ตร.ม. โครงการเดิมยัง 15,000 บาท สรุปนี้อ่านจากผลส่งมอบของแชตนั้น ไม่ใช่การทดสอบหน้าจอซ้ำในรอบอัป GitHub

รอบนี้รัน npm test ใหม่ผ่าน 121/121 และ npm run build ผ่าน ก่อนผ่านพบ fixture ทดสอบย้ายฐาน 18 ตารางใส่ลูกก่อนแม่ตาม UUID แบบสุ่ม จึงปรับเฉพาะ fixture ให้ INSERT ใน transaction ที่ตรวจ FK เมื่อ COMMIT โดยไม่ปิด foreign keys และยังตรวจ foreign_key_check หลังเปิดฐานใหม่ ไม่เปลี่ยนสูตรหรือ migration จริง

## ข้อจำกัดและสิ่งที่ไม่ได้ทำ

ยังเป็น local trial ไม่มีระบบสิทธิ์ออนไลน์หรือรองรับหลายผู้ใช้ ข้อมูลจริง/ราคาซื้อ/ขอบเขตและความพร้อมใช้งานต้องตรวจรับแยก ไม่รวมใบเสนอราคาลูกค้าสมบูรณ์ ภาษี ส่วนลด สต็อก และ PO ไม่มีการแก้ InsForge หรือ deploy Vercel ในรอบนี้

GitHub เก็บเฉพาะ source และเอกสาร ไม่ส่งฐานข้อมูลบนเครื่อง ข้อมูลนำเข้าจริง ไฟล์สำรอง credentials หรือ artifacts ขึ้น public repository ฐานเดิมในเครื่องยังอยู่และไม่ถูกแก้ด้วยการอัป GitHub
