# ลิงก์ทดลองตรวจสูตรเฟส 2

> อัปเดตล่าสุด: ลิงก์เดิมแยกสี่รายการตาม Master 1.7 แล้ว ดู [วิธีทดสอบรุ่นใหม่](B01-WEB-TRIAL.md) ข้อความรุ่นก่อนด้านล่างเก็บไว้เป็นประวัติ

> ลิงก์นี้ยังเป็นโครงสร้างรุ่นก่อนแยกท็อปหิน ไม่ใช่ฉบับตรวจรับตาม Master 1.7 ดู [แบบ B01 ล่าสุด](B01-STRUCTURE.md) การปรับเอกสารรอบนี้ยังไม่ได้อัปเดตเว็บ

เปิดที่ https://smart-boq-new-test-web.vercel.app

วันที่ 23 ตุลาคม 2569 เจ้าของขอลิงก์เพื่อทดสอบก่อนพัฒนาหน้าบ้านเต็ม จึงสร้างหน้าทดลองเฉพาะการคำนวณและรูปแบบ Excel ไม่ถือว่าเฟส 3 ทั้งหมดหรือการตรวจสิทธิ์ Import ผ่านบัญชีจริงเสร็จแล้ว

## ทดลองได้แล้ว

- กรอกเมตรขายและพื้นที่หน้าบานแยกกัน ราคา อัตราใช้ เผื่อเศษที่กรอกเอง และ margin
- เรียกแกนคำนวณจริงใน InsForge ใหม่ รวมต้นทุน ราคาขาย และงบซื้อหลังรวมวัสดุทั้งโครงการ
- ตัวอย่าง CUSTOM ขายรวม 76,039.10 บาท และ VS Modular ขายรวม 92,914.10 บาท เมื่อใช้ค่าตั้งต้นตามมาสเตอร์
- ส่งออกผลคำนวณเป็น Excel และใช้หน้าพิมพ์ของเบราว์เซอร์เพื่อบันทึก PDF (ยังไม่ใช่ตัวสร้าง PDF ฝั่ง server)
- ดาวน์โหลด Excel SAMPLE วัสดุ ค่าแรง VS Modular แล้วอ่านไฟล์ที่แก้กลับเพื่อดูข้อมูลและตรวจรูปแบบ

## ยังไม่เปิด

- เข้าสู่ระบบ/สร้างบริษัท บันทึกโครงการ ล็อกโครงการ และ Import บันทึกลงคลัง
- การอ่าน Excel กลับในลิงก์นี้เป็นการตรวจรูปแบบในเบราว์เซอร์เท่านั้น ไม่ใช่การจับคู่หรือบันทึกในฐาน จึงไม่ใช้แทนการทดสอบ Import ด้วยบัญชีจริง
- คำเตือนสิทธิ์ preview/commit 2 จุดในรายงานเฟส 2 ยังเป็นงานค้าง ต้องทดสอบ token ของผู้ใช้จริงก่อนเปิดงานเขียนคลัง ฟังก์ชัน onboarding ที่เตรียมไว้ปิดสิทธิ์ไว้ ยังไม่ให้เรียกจากเว็บ
