1. ข้อสรุปสำหรับเจ้าของโครงการ

พร้อมพัฒนาต่อจากต้นแบบในเครื่อง แนวทางหลักสอดคล้องกับมาสเตอร์เมื่ออ่านร่วมกับคำยืนยันล่าสุดของเจ้าของ: เริ่มจากงานที่ขาย → กลุ่มงาน/ชุด → วัสดุและค่าแรง เลือกซื้อหรือผลิตแยกชุด เก็บต้นทุนแยกกลุ่ม และรวมเฉพาะรายการที่ต้องจัดหาจริงตอนสรุปซื้อ

ไม่พบข้อขัดแย้งในสูตรหลักที่เป็นเหตุให้ต้องย้อนออกแบบใหม่ แต่ยังไม่ใช่การตรวจรับระบบใช้งานจริง มีข้อกำหนดที่ต้นแบบยังทำไม่ครบ โดยเฉพาะสิทธิ์และการบันทึกฝั่ง server การตรวจขอบเขตซ้ำระดับตำแหน่ง/เหตุผล หลักฐานราคาจริง และรายงานส่งออกครบตามแบบใหม่ รายละเอียดอยู่หัวข้อ 8

พบข้อความรุ่นเก่าในมาสเตอร์และเอกสารออกแบบที่อาจอ่านแล้วขัดกับหน้าจอปัจจุบัน จึงเพิ่มหัวข้อ 0.3 ใน MASTER และเชื่อมเอกสารนี้เป็นสถานะอ้างอิงล่าสุด โดยเก็บตัวอย่างเก่าไว้เป็นประวัติ ไม่เปลี่ยนสูตรธุรกิจหรือทำให้ข้อกำหนดที่ยังไม่เสร็จกลายเป็นผ่านแล้ว

รอบทบทวนนี้ตรวจไฟล์และโค้ดใน smart-boq-new รันการทดสอบและ build ในเครื่อง ไม่เรียกฐานออนไลน์ ไม่ตรวจสิทธิ์ด้วยบัญชีจริง ไม่แก้ migrations/RPC และไม่เผยแพร่เว็บ ภาพและตัวเลขเป็น SAMPLE

5. กติกาคำนวณที่ยืนยันและใช้แล้ว

ปริมาณแผงและวัสดุ

  • พื้นที่แผง 1 ตร.ม. คือพื้นที่ด้านเดียว บุไม้อัด 2 ด้านใช้ไม้อัด 2 ตร.ม.
  • ลามิเนตเท่ากับพื้นที่ไม้อัดด้านที่เลือกปิดผิว ไม่จำเป็นต้องปิดทุกด้าน
  • ไม้โครงใช้พื้นที่แผง × อัตราเมตรไม้ต่อ ตร.ม. ที่ผู้ใช้ระบุ
  • กาวใช้พื้นที่ปิดผิว × อัตราใช้ที่ผู้ใช้ระบุ ไม่เดาอัตราครอบคลุมหรือคูณสองพื้นผิวซ้ำ
  • ไม่คูณพื้นที่แผงด้วยเมตรขายซ้ำ ไม่เพิ่มเผื่อเศษหรือหักช่องเอง

ต้นทุนและราคาขาย

ราคาต่อหน่วยใช้ = ราคาต่อหน่วยซื้อ ÷ ปริมาณที่ได้ต่อหน่วยซื้อ
ต้นทุนบรรทัด = ปริมาณใช้รวมเผื่อที่กรอก × ราคาต่อหน่วยใช้
ต้นทุนกลุ่ม = รวมบรรทัดคิดเงินจริง ทั้งวัสดุและค่าแรงในกลุ่ม
ต้นทุนกลุ่มต่อเมตร = ต้นทุนกลุ่มก่อนปัด ÷ เมตรขาย S001
ต้นทุนรวม S001 = รวมกลุ่มที่เปิดใช้ + ต้นทุนร่วม ครั้งเดียว
ราคาขายต่อหน่วย = ต้นทุน S001 ต่อหน่วย ÷ (1 − กำไร%/100)
ราคาขายรวม = ปริมาณขาย × ราคาขายต่อหน่วยที่ปัด 2 ตำแหน่งแล้ว

ใช้ Decimal ความละเอียดสูงและ HALF_UP ตามมาสเตอร์ ไม่รวมต้นทุนจากตัวเลขรายบรรทัดที่ปัดแสดงผลแล้ว กำไร 40% ของราคาขายใช้ตัวหาร 0.60 ไม่ใช้ต้นทุน × 1.40 ส่วนต่างยังไม่ใช่กำไรสุทธิ

สินค้าชุดและค่าแรง

  • CHARGEABLE คือบรรทัดคิดเงินจริง มีผลต่อต้นทุนและการจัดหา
  • INCLUDED_REFERENCE คือของที่รวมแล้ว เปิดดูได้ แต่ไม่บวกต้นทุนหรือสั่งซื้อเดี่ยว
  • EXCLUDED_REFERENCE คือชุดไม่รวม ต้องเพิ่มบรรทัดจริงพร้อมจำนวน หรือยืนยันว่าไม่ต้องใช้
  • จำนวนอ้างอิง = จำนวนใช้ของชุดแม่ × จำนวนต่อชุดตาม snapshot ไม่คูณเมตรขายอีก ถ้าไม่ทราบใช้ null
  • แรงผลิต/ประกอบและแรงติดตั้งเก็บในกลุ่มงานของตน แยก laborPhase และฐานปริมาณ อัตราต่อเมตรคูณเมตรขาย แต่ปริมาณรวมไม่คูณซ้ำ
  • ราคาซื้อชุดที่ผู้ขายไม่แยกแรงผลิตเก็บเต็มในคอลัมน์วัสดุ/สินค้าชุด ไม่เดาแบ่งราคาแรงภายใน คอลัมน์ค่าแรงแสดงเฉพาะที่คิดเพิ่ม
  • ของเพิ่มทับขอบเขตชุดต้องตรวจและยืนยัน เปลี่ยนจำนวน/วิธีคิด/ประเภท/ชุดแม่ต้องตรวจการยืนยันใหม่ ไม่หักหรือแก้ของเพิ่มให้เอง

สรุปซื้อ

รวมวัสดุที่คิดเงินจริงรหัสเดียวกันจากทุกกลุ่ม/งานก่อนปัดตามขั้นซื้อ ใช้ราคาอ้างอิงโครงการสำหรับงบซื้อ คงราคาบรรทัด snapshot สำหรับต้นทุน ไม่รวม LABOR หรือรายละเอียดที่รวมในชุดเป็นวัสดุซื้อ และปริมาณเหลือเป็นเพียงค่าทฤษฎี ไม่ใช่สต็อก

พื้นที่ด้านเดียวและจำนวนด้านสอดคล้องคำยืนยันล่าสุดเป็นการขยาย D02 เดิม ไม่ใช่การถอดมิติตู้อัตโนมัติ
BUY/MAKE รายกลุ่มสอดคล้องแบบ 18 ตารางแทนสวิตช์วิธีผลิตทั้ง S001 รุ่นเก่า
ค่าแรงแยกกลุ่มสอดคล้องคำยืนยันล่าสุดไม่ต้องเพิ่มตารางจาก 18 ตาราง
กำไร/Decimal/การปัดเศษสอดคล้องสูตร Master 5.1–5.3การทดสอบ local ผ่าน ไม่ยืนยันผล backend รุ่นใหม่
รวมซื้อก่อนปัด/ไม่รวมแรงเป็นวัสดุสอดคล้องสูตร Master 5.4แค่โครงการจำลอง ไม่ใช่หลายบริษัทบนฐานจริง
คง snapshot และตรวจการเปลี่ยนวิธีมีในต้นแบบtransaction/version/lock ฝั่ง server ของแบบใหม่ยังต้องทำ
ไม่คิดของ/แรงในชุดซ้ำผ่านกรณี SAMPLE ที่มี testsยังไม่ครบการระบุตำแหน่ง เหตุผล และข้อบังคับฝั่ง server ตามแบบเต็ม
คลังร่วมและ Excelมีต้นแบบและ tests ไฟล์ยังไม่ตรวจวงจรบัญชีจริง–ฐานจริงสำหรับแบบใหม่
Excel/PDF ผลคำนวณเดียวกันมี export Excel และทางพิมพ์ต้นแบบยังไม่ตรวจรับรายงานเต็มทุกคอลัมน์/ทุกหน้าแบบ 18 ตาราง
สิทธิ์บริษัทและสถานะ LOCKEDเป็นข้อกำหนดที่ยังคงอยู่ไม่ได้ตรวจหรือรับรองในการทบทวน local รอบนี้

7. ตัวอย่างปัจจุบันและหลักฐานตรวจ

ปริมาณขาย S001 3.50 เมตร ตัวเลขทั้งหมดเป็น SAMPLE

กลุ่มวัสดุ/สินค้าชุดแรงผลิตคิดเพิ่มแรงติดตั้งต้นทุนรวมต้นทุน/เมตร

DOOR ซื้อชุด2,000.000.00 รวมแรงในชุด2,100.004,100.001,171.43

ต้นทุนร่วม0.000.000.000.000.00

S001 ต้นทุนรวม 24,233.56 บาท ต้นทุนต่อเมตร 6,923.87 บาท ราคาขายต่อเมตร 11,539.79 บาท และราคาขายรวม 40,389.27 บาท เมื่อกำไรเป้าหมาย 40% ของราคาขาย ไม่รวม S002–S004 ตัวอย่างเก่าตัวเลขต่างกันเพราะคนละข้อมูลปริมาณ/ขอบเขต ไม่ใช่ยอดบังคับของทุกโครงการ

ตรวจอัตโนมัติรอบทบทวน: 80 กรณีผ่านทั้งหมด และ npm run build ผ่าน มีคำเตือน SDK เรื่อง crypto ที่ถูก externalize สำหรับเบราว์เซอร์ ไม่ใช่ build ล้ม แต่ยังต้องตรวจ integration เมื่อพัฒนาส่วนออนไลน์

กลุ่มทดสอบตัวอย่างสิ่งที่ครอบคลุม
สูตรและโครงสร้าง B01หน่วยขายถูกต้อง ไม่คูณหิน/พื้นที่หน้าบานตามเมตรตู้ งานอื่นไม่เปลี่ยนตาม S001
แผงและกลุ่มจำนวนด้าน ปิดลามิเนตศูนย์ด้าน เลือกสเปก/ราคา/เผื่อแยกกลุ่ม รวมซื้อก่อนปัด
สินค้าชุด2 ชุดได้บานพับ 4 ตัวอ้างอิง ไม่คิดซ้ำ ของเพิ่ม/ไม่รวม/ไม่ทราบ แม่ลูกผิดหรือซ้ำ
ค่าแรงและคอลัมน์ผลิต/ติดตั้งแยก ถูกนับในต้นทุนกลุ่ม ไม่เข้าแผนซื้อวัสดุ ไม่เดาประเภทแรงเก่า
ร่างและตัวตนโหลดกลับได้ สำรองก่อนแปลง storage error ไม่รายงานว่าสำเร็จ ย้ายแรงโดยไม่คัดลอก
คลังและ Excelรหัส/ทศนิยม/version แท็ก นำซ้ำไม่สร้างซ้ำ ปฏิเสธข้อมูลผิดหรือขัดแย้ง

หลักฐาน: ผลทดสอบรอบนี้, ผล build รอบนี้, ภาพคอลัมน์กลุ่มงาน, ภาพค่าแรงและต้นทุนต่อเมตร

การตรวจหน้าจอในรอบพัฒนาก่อนหน้าครอบคลุมการสลับซื้อ/ผลิต การเพิ่มแรงที่รวมในชุดแล้ว การลบ/เลิกทำ และโหลดร่างใหม่ รอบทบทวนนี้ตรวจหน้าจอปัจจุบันแบบอ่านข้อมูล ไม่เปลี่ยนจำนวนหรือราคาของผู้ใช้

8. สิ่งที่ยังไม่ครบและต้องจัดการก่อนใช้จริง

ลำดับสิ่งที่ยังขาดผลกระทบ/งานต่อ
A1ข้อความประวัติ 16/17 ตาราง วิธีผลิตทั้ง S001 และ D02 แบบเดิมระบุสถานะและกติกา 0.3 ให้ชัดแล้ว เก็บประวัติเพื่อย้อนตรวจได้
A2แบบ 18 ตารางยังไม่ติดตั้งในฐานต้องทำ migration, FK, UNIQUE, version, transaction, RLS และทดสอบแยกบริษัท/สถานะล็อกในระบบทดสอบใหม่ก่อน
A3การยืนยันของเพิ่มยังเป็น checkbox ผูกข้อมูลบรรทัด/แม่ใน localยังไม่ครบเหตุผล ผู้ยืนยัน ตำแหน่ง และขอบเขตทั้งงานตาม relation 18; ต้องทำใน server และห้ามถือว่าติ๊กแล้วผ่านล็อกจริง
A4ราคาจริง สเปก Index และขอบเขตรวม/ไม่รวมยังเป็น SAMPLE/PENDINGต้องใช้หลักฐานผู้ขาย อัตราไม้/กาว/ค่าแรงจริง และขั้นรับรองก่อนล็อก ห้ามนำ SAMPLE ไปใช้เป็นราคาจริง
A5ราคาศูนย์/จำนวนศูนย์และงานต้นทุนไม่ครบต้นแบบยังไม่มีกระบวนการรับรองราคาศูนย์และความครบก่อนล็อกตาม Master; การกรอกได้ไม่เท่ากับผ่านตรวจรับ
A6รายงานเปรียบเทียบราคา snapshot บรรทัดกับราคาโครงการตัวคำนวณแยกสองราคาแล้ว แต่ยังขาดรายงานเตือนเปรียบเทียบตาม Master 5.4
A7แบบฟอร์มหน่วยและรายงานเต็มต้องทำการแปลงจากมิติ/จำนวนบรรจุที่ตรวจแล้ว ไม่ให้ yield เป็นช่องอิสระในงานจริง และตรวจ Excel/PDF จากข้อมูลเดียวกัน รวมคอลัมน์กลุ่ม/ประเภทแรงและหน้าเอกสาร
A8ขอบเขต UI ยังเป็นสามกลุ่มตัวอย่างใน S001ยังไม่ใช่ตัวสร้างกลุ่มทั่วไปทุกงาน สูตรลิ้นชักยังกรอกเอง และการเลือกสินค้าชุดย่อยในงาน MAKE ยังไม่มีเส้นทาง UI ครบตามแบบ
A9ข้อจำกัด BOM/การเก็บข้อมูลไม่รองรับชุดซ้อนชุดหรือกลุ่มซ้อนกลุ่มตามขอบเขตรุ่นนี้; localStorage ไม่ใช่ระบบสำรอง/ประวัติส่วนกลาง ไม่มีการล็อกงานจริง

ข้อ A2–A9 เป็นช่องว่างก่อนตรวจรับระบบเต็ม ไม่ควรสรุปว่าไม่เหลืองานค้างเพียงเพราะชุดทดสอบ local ผ่าน และไม่จำเป็นต้องเปลี่ยนจำนวนตารางเพียงเพราะมีขั้นตอนพัฒนาเหล่านี้

9. ลำดับพัฒนาต่อที่แนะนำ

  1. ใช้ Master 0.3 + relation 18 + เอกสารนี้เป็นฐานส่งต่อ ยืนยันตัวอย่างงานจริงหนึ่งชุดพร้อมสเปกและขอบเขต ไม่เปิดหลายฟีเจอร์พร้อมกัน
  2. ทำความครบของต้นแบบก่อนต่อฐาน: เหตุผล/ตำแหน่งของเพิ่ม ข้อมูลที่รอตรวจ ราคาศูนย์ การเตือนราคาต่าง และกรณีสลับวิธีที่มีค่าแรง/รายการเพิ่มอยู่แล้ว
  3. เตรียม schema/migration และ RPC แบบ 18 ตารางสำหรับระบบทดสอบแยก พร้อมแผนสำรองและทดสอบย้อนกลับ ก่อนขออนุมัติลงฐาน ไม่มีการอนุมัติการแก้ฐานจากรายงานนี้
  4. เชื่อมบัญชี–บริษัทและการบันทึกจริง ทดสอบ snapshot, concurrent version, lock และการปฏิเสธข้ามบริษัทบน server แล้วเทียบผลกับตัวคำนวณในเครื่อง
  5. ทำรายงาน Excel/PDF จากผลเดียวกัน ตรวจทุกกลุ่มและชุดอ้างอิงให้ครบ แล้วทดลองงานจริงที่ได้รับอนุญาต เก็บข้อผิดพลาดก่อนพิจารณาเผยแพร่

web/main.mjsเชื่อมหน้าจอ payload คำนวณ สรุปซื้อ และ export

lib/catalog-excel.mjsอ่าน/เขียนไฟล์คลัง Excel
