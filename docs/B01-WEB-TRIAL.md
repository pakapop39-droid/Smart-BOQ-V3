# เว็บทดลอง B01 ฉบับ 1.7

ลิงก์: https://smart-boq-new-test-web.vercel.app

## วิธีลอง

1. ตาราง B01 แสดงตู้เตี้ย 3.50 เมตร ท็อปหิน 2.10 ตร.ม. ผนังกรุ 6 ตร.ม. และซิงก์ 1 ชุด กรอกปริมาณขายและกำไรแยกรายการ
2. กด “เปิดต้นทุน S001” เพื่อเลือกผลิตเองหรือ VS Modular และกรอกพื้นที่หน้าบาน วิธีผลิตและพื้นที่หน้าบานอยู่เฉพาะรายละเอียดตู้
3. กด “กลับตาราง B01” แล้วเปิด S002/S003/S004 เพื่อตรวจและแก้ต้นทุนของแต่ละงาน ท็อปใช้หิน 1 ตร.ม.ต่อ 1 ตร.ม.ขาย ไม่คิดซ้ำในตู้
4. แก้ราคาซื้อร่วมได้ในแถบคลัง SAMPLE แล้วกด “คำนวณ B01 ผ่าน InsForge” ราคากลับมาที่แต่ละแถวของ B01 พร้อมสรุปราคาขายและงบซื้อด้านล่าง
5. เมื่อเปลี่ยนข้อมูล ยอดเดิมถูกล้างเพื่อให้กดคำนวณใหม่ สามารถส่งออกผลเป็น Excel หรือใช้หน้าพิมพ์เพื่อบันทึก PDF

ตัวอย่างทั้งหมดใช้ margin 40%: CUSTOM ตู้ขาย 30,333.35 + หิน 10,500.00 + ผนัง 25,872.42 + ซิงก์ 9,333.33 = 76,039.10 บาท; VS Modular ตู้ขาย 47,208.35 รวม B01 92,914.10 บาท

## สิ่งที่ปรับและตรวจ

- แยกตารางต้นทุนสี่รายการ ไม่มี ST01 ในต้นทุนตู้ทั้งสองวิธี
- หน่วยขายหินเป็น ตร.ม. ปริมาณ 2.10 กรอกเอง ไม่เพิ่มสูตรถอดมิติ และไม่เปลี่ยนตามเมตรขายตู้
- แก้ต้นทุนผนังได้โดยไม่แก้ต้นทุนตู้อีกตาราง แต่ราคาทะเบียน SAMPLE ร่วมกันเมื่อเป็นวัสดุรหัสเดียวกัน
- ทดสอบอัตโนมัติ 8 กรณีผ่าน รวม Excel เดิมและโครงสร้างใหม่; SDK เรียก InsForge จริงตรวจต้นทุน/ราคาสี่รายการและสองวิธีตู้ผ่าน ดู artifacts/trial-api-tests.json
- ทดสอบเบราว์เซอร์เปิดต้นทุน S001–S004 ตรงรายการ แสดงตัวเลือกวิธีผลิตเฉพาะตู้ และคำนวณผ่านลิงก์จริง

## ขอบเขต

เป็นการอัปเดตเว็บคำนวณทดลอง ไม่ใช่การเปิดแอปเต็ม ยังไม่บันทึกโครงการหรือ Import เข้าคลัง และยังต้องตรวจสิทธิ์การเขียนด้วยบัญชีจริงก่อนเปิดส่วนดังกล่าว ไม่มี migration หรือการแก้ข้อมูลถาวรในรอบนี้ ใช้ API คำนวณที่รองรับหลายรายการอยู่แล้ว ข้อปรับ schema ที่ระบุในแบบยังเป็นงานของรอบระบบบันทึกจริง ไม่อ้างว่าทำแล้ว

ระบบเดิมไม่ถูกแก้ไข ราคาทั้งหมดเป็น SAMPLE ไม่ถือว่า Index/ขอบเขต/ราคาจริงผ่านการตรวจ การเปลี่ยนวิธีผลิตในเว็บนี้คืนตัวอย่างต้นทุนตู้ของวิธีนั้น ไม่แตะหิน ผนัง หรือซิงก์
