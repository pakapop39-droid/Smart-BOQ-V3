# Smart BOQ V3 — คลังราคาขายต่อหน่วยแบบ A

24 ตุลาคม 2569 · ตามคำยืนยันล่าสุดของคุณต๋องให้เปิดตารางทีละชั้น · ทำในเครื่อง รอเจ้าของทดลอง

## แนวทางปัจจุบัน

คลังราคาขายต่อหน่วย → เลือกรายการ → ตารางส่วนประกอบ เช่น ตัวตู้/หน้าบาน → เลือกส่วนประกอบ → ตารางวัสดุและค่าแรง ถ้าเป็นสินค้าชุดที่มีรายละเอียดรวม/ไม่รวม ให้เปิดตารางของในชุดต่อได้

แต่ละครั้งเปลี่ยนตารางในพื้นที่หลักเต็มพื้นที่ ไม่กางแถวลูกใต้ตารางเดียวกัน ไม่ใช้แผงขวาแทนตารางส่วนประกอบ มีเส้นทางที่กดย้อนกลับได้และปุ่มย้อนกลับทีละชั้น แถวปลายทางที่ไม่มีรายการย่อยไม่เปิดแผงขวาเอง การแก้ข้อมูลต้องกดปุ่มแก้อย่างชัดเจน ชื่อรายการบนสุดเป็นปุ่มลูกศรเปิดส่วนประกอบเช่นเดียวกับรหัสและปุ่มหลัก

แก้จุดเข้าหลังเจ้าของทดลอง: ปุ่มหลักในคลังทุกสถานะเป็น “เปิดส่วนประกอบ” แทนปุ่ม “แก้ข้อมูล” ของรายการร่าง ตารางส่วนประกอบมีปุ่มเปิดตารางเป็นทางหลัก การแก้ข้อมูลอยู่ภายในรายการ/ส่วนประกอบ ตรวจจากแท็บเดิมหลังโหลดใหม่ พบปุ่มเปิดส่วนประกอบ 6 แถว ปุ่มแก้ข้อมูลที่หน้าคลัง 0 แถว และเปิด RT003→ต้นทุนตรง→วัสดุ/ค่าแรงโดยไม่เปิด drawer; build ผ่าน หลักฐาน entry-fixed-real-tab.png

กลุ่มใช้ข้อมูล rate_template_groups เดิม บรรทัดใช้ rate_template_cost_lines เดิม และของในชุดใช้ parent_id เดิม ไม่เพิ่ม schema หรือสร้างกลุ่ม/วัสดุจากชื่ออัตโนมัติ ไม่รองรับกลุ่มซ้อนกลุ่มลึกได้ไม่จำกัดโดยแอบเปลี่ยนแบบข้อมูล

รายการเดิมที่ลงต้นทุนตรง เช่น RT003 แสดงแถว “ต้นทุนตรง (ไม่แยกกลุ่ม)” เป็นทางเข้าตารางต้นทุนเดิมเท่านั้น ไม่ใช่กลุ่มที่เพิ่มในฐาน และไม่ย้าย/คัดลอก/คิดต้นทุนซ้ำ รายการที่ยังว่างยังเข้าเพิ่มต้นทุนตรงหรือเพิ่มส่วนประกอบได้

## พฤติกรรมที่คงไว้

- คำค้นและตำแหน่งเลื่อนตารางจำแยกตามชั้นระหว่างเปิดใช้งาน กลับหน้าคลังยังคงคำค้น/สถานะเดิม ไม่อ้างว่าเส้นทางเก็บข้ามการรีเฟรชเบราว์เซอร์
- เปิดชั้นใหม่/ย้อนชั้นล้างการเลือกหลายแถว เลือกทั้งหมดเฉพาะต้นทุนที่ลบได้ในตารางที่แสดง ไม่รวมของในชุดที่เป็นอ้างอิง
- คำนวณร่างทันทีผ่านแกนเดิม แสดง “ต้นทุนส่วนนี้” แยกจาก “ต้นทุนรวมรายการ” และราคาขายต่อหน่วย ถ้ามีค่าค้างต้องเลือกบันทึก/ทิ้ง/อยู่ต่อก่อนเปลี่ยนชั้น
- ยังคงลบต้นทุนหลายแถวและเลิกทำทั้งชุด ข้อมูลรุ่น READY อ่านอย่างเดียวและสร้างรุ่นถัดไปเพื่อแก้ตามเดิม
- รายละเอียดที่รวมในชุดแสดงว่าไม่บวกเงินซ้ำ ไม่รวมต้นทุนจากแถวลูกอ้างอิงซ้ำกับชุดแม่
- คลังวัสดุ/ค่าแรง/VS Modular ยังคงหน้าคลังและแผงขวาตามรอบก่อน ไม่เปลี่ยนโฟลว์ Keyplan หรือ snapshot โครงการ

## การเปลี่ยนโค้ดและผลตรวจ

ปรับ web/local-rate-workspace.mjs เป็นตารางส่วนประกอบ/วัสดุ/ของในชุด พร้อม breadcrumb และ back ปรับการป้องกันค่าค้างใน drawer และ scope การเลื่อนตาราง เพิ่มเพียง templateGroupId ในผล local rate-preview เพื่อชี้ยอดกลุ่มจากแกนเดิมกลับมายังกลุ่มคลัง ไม่เพิ่ม fields ที่จัดเก็บ ไม่เปลี่ยนสูตรหรือรวมตัวเลขที่ปัดรายแถวขึ้นใหม่

- ทดสอบรวม 183/183 และ build ผ่าน เพิ่ม 3 กรณีแยกชั้นตาม template/group/variant/parent การเปิดต้นทุนตรงโดยไม่เพิ่มกลุ่ม และ mapping ยอดกลุ่มจาก core พร้อมยืนยัน preview ไม่ทิ้งข้อมูล
- ตรวจ UI บนฐานสำเนาที่พอร์ต 5188 มีตู้เตี้ย QA แยกตัวตู้ MAKE กับหน้าบาน BUY เปิดตารางต่อและของในชุดได้จริง ยอดไม่เปลี่ยนเพราะเพียงเดินตาราง
- ทดสอบไม้โครง 8→10 เมตร: 92.80→116.00 บาท ต้นทุนตัวตู้ 2,083.08→2,106.28 บาท ต้นทุนรวม 3,083.08→3,106.28 บาท ขายต่อเมตร 5,138.46→5,177.13 บาท ใช้ margin/การปัดเดิม
- ตรวจทิ้งค่าค้างและบันทึกแล้วกลับชั้นบน คำค้น WD01 กลับมาเมื่อเปิดส่วนประกอบเดิม ลบสองแถวแล้วเลิกทำคืนค่าและยอดทั้งชุด
- ข้อมูลตัวอย่างตู้เตี้ยและการเปลี่ยนตัวเลขอยู่เฉพาะฐาน QA ไม่เพิ่มข้อมูลทดลองในฐานหลัก ตรวจ state ฐานหลักและ hash แกนคำนวณเดิม พร้อมผลคำนวณทั้ง 4 โครงการ

หลักฐานอยู่ใน artifacts/rate-drilldown-a-20261024 ไม่ส่งขึ้น Git ไม่มีการเชื่อม InsForge deploy หรือ push GitHub ผลทดสอบไม่แทนเจ้าของรับรองราคาจริงหรือรับรูปแบบ
