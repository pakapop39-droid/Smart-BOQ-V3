# ซื้อเป็นฟุต/หลา ใช้เป็นเมตร

ในคลัง เลือกหน่วยซื้อ **ฟุต** หรือ **หลา** ระบบเลือกหน่วยใช้ **เมตร** และวิธี **แปลงหน่วยความยาว (LENGTH_UNIT)** ให้เอง ไม่ต้องกรอกความยาวหรือตัวคูณซ้ำ กรอกราคาต่อหน่วยซื้อเพื่อเห็นราคาต่อเมตรทันที

| หน่วยซื้อ | ความยาวที่ได้ | ตัวอย่างราคาซื้อ | ต้นทุนต่อเมตร |
|---|---:|---:|---:|
| 1 ฟุต | 0.3048 เมตร | 30.48 บาท/ฟุต | 100 บาท/เมตร |
| 1 หลา | 0.9144 เมตร | 91.44 บาท/หลา | 100 บาท/เมตร |

ใช้หน่วยสากลตาม [NIST SP 811 Appendix B](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors) เก็บตัวคูณเป็นข้อความตรง ไม่ปัดก่อนใช้ Decimal แกนเดิม ไม่ใช่หน่วยฟุตสำรวจที่ดินสหรัฐ และไม่ปะปนกับตารางฟุต/ตารางหลา หากเลือกหน่วยใช้ผิดมิติ API จะปฏิเสธ

เพิ่มเพียงทะเบียนหน่วย 2 รายการแบบไม่ซ้ำ ไม่เปลี่ยนรหัส หน่วย ราคา หรือ snapshot ของรายการเดิม ไม่เพิ่มตาราง รองรับ Excel local v3 ด้วย conversion_method=LENGTH_UNIT และ purchase_unit_code=ฟุต/หลา, usage_unit_code=เมตร ในคอลัมน์เดิม สำรองและกู้คืนได้ การเปลี่ยนหน่วยวัสดุที่ถูกใช้งานแล้วต้องสร้างรหัสวัสดุใหม่ตามกติกาเดิม

ผลตรวจ: ทดสอบรวม 197/197 และ build ผ่าน ตรวจตัวคูณ หน่วยผิด rollback preview ไม่บันทึก Excel/backup ไม่ซ้ำ ต้นทุนผ่านแกนเดิม และราคา snapshot ไม่เปลี่ยนตามราคาคลังที่แก้ทีหลัง ตรวจ UI ฟุตและหลาแล้วทิ้งร่างทดสอบทั้งหมด ไม่เพิ่มวัสดุ QA ลงคลังจริง หลักฐาน artifacts/length-units/ ไม่ส่งขึ้น Git ทำในเครื่อง ไม่เชื่อมออนไลน์หรือ push รอบนี้
