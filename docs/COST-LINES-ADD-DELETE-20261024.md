# ตารางต้นทุนใช้เพิ่ม–ลบ ไม่มีเปิดใช้/ปิดใช้

ตามคำยืนยันคุณต๋อง: บรรทัดต้นทุนเป็นการเลือกวัสดุ/ค่าแรงจากคลังมาประกอบราคา เพิ่มแล้วใช้คำนวณ ไม่ต้องมีสวิตช์เปิดใช้/ปิดใช้ในฟอร์มต้นทุนของคลังราคาขายและรายการโครงการ การลบเอาเฉพาะบรรทัดออก ไม่ลบวัตถุดิบในคลัง เลือกหลายบรรทัดและเลิกทำได้ตามขอบเขตรุ่นร่าง/การปรับเฉพาะโครงการเดิม

- เอาช่องเปิดใช้/ปิดใช้ออกจากฟอร์ม `rate_template_cost_lines` และ `component_cost_lines` เพิ่ม/บันทึกบรรทัดให้รวมคำนวณเสมอ ไม่เปลี่ยนการเปิดใช้ของทะเบียนวัสดุหรือต้นแบบทั้งรายการ
- รายการต้นทุนคิดเงินจริงทุกบรรทัดที่แสดงเลือกได้ รวมข้อมูลเก่าที่เคยปิดไว้ API ลบยอมรับบรรทัดเก่าเหล่านี้ และรองรับ group_id ว่างแบบเก่า
- ของในชุดเป็นรายละเอียดอ้างอิง ไม่ใช่บรรทัดคิดเงินอิสระ เลือกลบชุดแม่จะลบ/คืนลูกและขอบเขตพร้อมกัน ไม่เปิดให้ลบลูกจนชุดขาดหรือคิดเงินซ้ำ
- เลิกทำคืนจำนวน ราคา snapshot และตำแหน่งทั้งชุด รุ่นร่างยังใช้การตรวจ version กันคืนทับการแก้ไขภายหลัง การคืนบรรทัดคลังที่เคยปิดใช้มาก่อนให้รวมคำนวณตามกติกาใหม่ด้วย ไม่คืนสวิตช์ที่ซ่อนต้นทุน
- GL01 กาวยางใน RT003 ถูกลบเฉพาะจากตารางต้นทุนตามคำสั่ง คงกาวยางในคลังและประวัติเลิกทำไว้ เดิมไม่รวมยอดอยู่แล้วจึงคงต้นทุน 683.08 และขาย 1,138.46 บาท/ตร.ม. หากคืน GL01 ผ่านเลิกทำ อัตราเดิมคือ 300/1 ลิตร ซึ่งจะรวมคำนวณตามกติกาใหม่ ควรตรวจจำนวนก่อนใช้งาน

สำรองก่อนทำไว้ใน `artifacts/cost-add-delete/backup-before.json` ไม่ส่งข้อมูลฐาน/สำรองขึ้น Git ตรวจ UI ช่องติ๊ก GL01→ลบ→แสดงเลิกทำ ฟอร์ม LM01 ไม่มีสวิตช์ ทดลองจำนวน 1→2 เห็นต้นทุนรวมร่าง 1,099.74 ขาย 1,832.91 ทันที แล้วคืน 1 และยกเลิกโดยไม่บันทึก ตรวจคลังยังอยู่และโครงการเดิมคงเดิม ชุดทดสอบ 186/186 และ build ผ่าน ทั้งหมดในเครื่อง ไม่เชื่อมออนไลน์
