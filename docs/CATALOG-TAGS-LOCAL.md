# คลังตัวอย่าง แท็กงาน และการเลือกหลายรายการ

สถานะล่าสุด: Master 1.9 เพิ่ม [บันทึกอัตโนมัติในเบราว์เซอร์](LOCAL-AUTOSAVE.md) แล้ว ข้อความเก่าเรื่องรีเฟรชคืนตัวอย่างเป็นประวัติก่อนปรับรุ่นนี้

23 ตุลาคม 2569 · Master 1.8 · ทดลองในเครื่องเท่านั้น

## สิ่งที่ใช้ทดลองได้

- เมนูคลังตัวอย่างมีวัสดุ ค่าแรง และ VS Modular รวม 21 รายการจากแหล่งตัวอย่างเดียวกับเครื่องคำนวณ
- แท็กงานชุดเดียวใช้ข้ามคลัง เริ่มต้นงานตู้ Built-in งานกรุผนัง และงานฝ้าตกแต่ง ไม้อัด PLY01 เป็นรายการเดียวที่ติดสามแท็ก
- ค้นหารหัส/ชื่อและเลือกหลายแท็กแบบตรงอย่างน้อยหนึ่งแท็ก มีทั้งหมดและยังไม่ติดแท็ก เลือกทั้งหมดเฉพาะรายการที่แสดงและเลือกได้ เปลี่ยนคำค้น แท็บ หรือตัวกรองแล้วล้างการเลือก
- จัดการแท็กได้ทั้งเพิ่ม เปลี่ยนชื่อ รวม ลบเฉพาะแท็ก และเลิกทำการลบ ก่อนลบแสดงจำนวนรายการที่ได้รับผลกระทบ ไม่ลบวัสดุหรือราคา
- ติ๊กหลายรายการเพื่อเพิ่ม/เอาแท็กออก หรือส่งออก Excel เฉพาะที่เลือก ชื่อซ้ำหลังตัดช่องว่างและปรับ Unicode ถูกปฏิเสธ ใช้คำสั่งรวมแท็กแทน
- เปิดต้นทุน S001–S004 แล้วกดเลือกต้นทุนจากคลัง ค้นหา/กรอง/เลือกเพิ่มหลายรายการในครั้งเดียว แถวที่มีแล้วปิดการเลือก และหิน ST01 เลือกเข้าต้นทุนตู้ไม่ได้
- เลือกต้นทุนหลายแถวแล้วลบที่เลือก มีประวัติการลบแยกตามงาน เลิกทำคืนทั้งชุดพร้อมตำแหน่งและตัวเลขเดิม ถ้าเพิ่มรหัสที่ลบกลับเองแล้ว ให้ลบแถวใหม่ก่อนเลิกทำ เพื่อไม่เพิ่มซ้ำ

## ความหมายของข้อมูล

ทะเบียนแท็กมีรหัสคงที่ในอายุของหน้าทดลอง ความสัมพันธ์ resource_code → tag_id[] แยกจาก kind/cost_type_code รายการเดียวติดหลายแท็ก ไม่เพิ่มระดับเหนือ B01 และแท็กไม่เป็นตัวแปรคำนวณ ไม่มีระบบหมวดย่อยเพิ่ม

คลังกับต้นทุนโครงการใช้ตัวอย่างชุดเดียวตั้งต้น แต่ราคาที่เลือกเข้าต้นทุนแล้วเป็น snapshot ประจำโครงการ Import เปลี่ยนคลังในเครื่อง ไม่เขียนทับราคาหรือชื่อในโครงการเดิม รายการรหัสเดิมที่มี snapshot ในโครงการจะใช้ snapshot เดิมต่อไป ไม่มีการอัปเดตราคาโครงการอัตโนมัติ

ยังไม่อนุมัติ/ตรวจข้อมูลจริง ไม่มี localStorage ไม่มีบันทึกฐาน รีเฟรชแล้วคืนตัวอย่าง ปุ่มคืนค่าตัวอย่างในหน้าประมาณราคาคืนเฉพาะตัวอย่างต้นทุนและราคาโครงการ ไม่ล้างแท็กในคลังที่กำลังทดลอง

## Excel

แม่แบบ 2 เพิ่มคอลัมน์แท็กงาน [tags] ท้ายทั้งสามชีต แยกชื่อด้วยขึ้นบรรทัดใหม่ในเซลล์ ช่องว่างล้างแท็ก แม่แบบ 1 ไม่มีคอลัมน์นี้จึงคงแท็กเดิม ระบบยังรับเฉพาะแม่แบบที่หัวคอลัมน์ตรง ไม่รับสูตร/macros/ลิงก์ตามข้อจำกัดเดิม

ไฟล์ที่มีรหัสภายในและรุ่นข้อมูลต้องตรงรายการในหน้าทดลอง แถวใหม่เว้นสองช่องนี้และใช้รหัสรายการใหม่ ก่อนนำเข้าแสดง ADD/UPDATE/NO_CHANGE/ERROR/CONFLICT พร้อมรายละเอียดก่อน–หลังและชื่อแท็กใหม่ ต้องยืนยันจึงเปลี่ยนข้อมูล หากข้อมูลเปลี่ยนหลังเปิดตัวอย่างให้เลือกไฟล์ใหม่ ปฏิเสธทั้งชุดถ้าพบข้อผิดพลาด

Import เดิมไม่เพิ่มรายการซ้ำ แถวหายไม่ลบรายการ ไฟล์เก่าที่เนื้อหาเหมือนเดิมไม่เพิ่มรุ่นข้อมูล การแก้เนื้อหาด้วยรุ่นเก่าที่ขัดแย้งจะถูกปฏิเสธ แม่แบบ 2 ปิดการส่งผ่าน helper RPC สำหรับนำเข้าฐานจนกว่าจะสร้างและตรวจ backend ของแท็กจริง

## ขอบเขตรอบถัดไป

โครงสร้าง tenant-scoped tag registry กับความสัมพันธ์หลายต่อหลาย สิทธิ์บริษัท การบันทึกจริง และการขยาย RPC ของ Excel ยังเป็นงานออกแบบ/พัฒนา backend รอบถัดไป รอบนี้ไม่เพิ่มตาราง ไม่แก้ migration หรือฟังก์ชัน InsForge และไม่ deploy Vercel

## วิธีทดลอง

1. เปิดคลังตัวอย่าง ค้นหาไม้อัด จะเห็นหนึ่งแถวและสามแท็ก ลองติ๊กแล้วเอาแท็กงานฝ้าออก/เพิ่มกลับ
2. เปิดจัดการแท็ก ลองเพิ่มชื่อใหม่ เปลี่ยนชื่อ รวม ลบ และเลิกทำ
3. เปิดต้นทุน S001 เลือกจากคลัง ติ๊ก PLY01 กับ WD01 แล้วเพิ่ม จะได้ต้นทุนตู้ 18,848.24 บาทจากเดิม 18,200.00 บาท
4. ติ๊กสองแถวที่เพิ่มแล้วลบที่เลือก ยอดกลับ 18,200.00 บาท เลิกทำทั้งชุดกลับ 18,848.24 บาท
5. ดาวน์โหลด Excel ทั้งคลังจากหน้า Excel หรือเฉพาะที่เลือกจากคลัง แก้แท็กด้วยขึ้นบรรทัดใหม่ในเซลล์ แล้วเลือกไฟล์กลับมาตรวจตัวอย่างก่อนยืนยัน
