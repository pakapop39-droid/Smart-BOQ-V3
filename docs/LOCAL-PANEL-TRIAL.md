# ทดลองแผงตู้ผลิตเองในเครื่อง — 23 ตุลาคม 2569

เปิด http://127.0.0.1:5177/ → ประมาณราคา → เปิดต้นทุน S001 → CUSTOM ผลิตเอง

คำยืนยันเจ้าของ: พื้นที่แผง 1 ตร.ม. หมายถึงขนาดด้านเดียว บุไม้อัดสองด้านใช้ไม้อัด 2 ตร.ม. ลามิเนตเท่ากับพื้นที่ไม้อัดที่ปิดผิว ปริมาณพื้นที่รวมแยกจากเมตรขาย ไม่คูณเมตรขายซ้ำ

หน้าทดลองรองรับหนึ่งกลุ่มแผงสเปกเดียว กรอกพื้นที่แผง จำนวนด้านบุไม้อัด 1/2 และจำนวนด้านปิดลามิเนต 0/1/2 ซึ่งไม่เกินด้านบุไม้อัด อัตราไม้โครง (เมตร/ตร.ม.แผง) และพื้นที่ครอบคลุมกาว (ตร.ม./ลิตร) เริ่มว่าง รอกรอก ไม่มีการกำหนดอัตราจริงแทนเจ้าของ

วัสดุแผงเป็น WD01/PLY01/LM01/GL01 ใช้ TOTAL และคำนวณปริมาณจากช่องแผงโดยตรง เผื่อเศษแก้แยกตามวัสดุได้ ไม่เพิ่มราคาเหมารวม PN01 ซ้ำ กาวคำนวณพื้นที่ลามิเนตหารพื้นที่ครอบคลุมต่อลิตรโดยตรง เก็บตัวหารไว้จนคำนวณเพื่อไม่ปัดระหว่างทาง กรณีไม่ปิดลามิเนตใช้กาวปิดผิวศูนย์ได้โดยไม่ต้องกรอก coverage

ร่างเก่ายังไม่เปลี่ยนตารางเอง กด “ใช้แบบแผงตู้ / คืนวัสดุแผงตู้” จึงแทน PN01, ED01 และสี่วัสดุแผงเดิมด้วยชุดเชื่อมพื้นที่ใหม่ โดยรักษาค่าเผื่อเศษของวัสดุที่มีอยู่ ค่าแรง/อุปกรณ์อื่นและ S002–S004 คงเดิม ล้างประวัติลบเฉพาะ S001 เพราะโครงสร้างเปลี่ยน ไม่แปลงพื้นที่หน้าบานเดิมเป็นพื้นที่แผงเอง

ED01 เดิมรวมกาวและขอบจึงนำออกเพื่อไม่คิดกาวซ้ำ งานขอบยังต้องระบุชนิด ปริมาณ ราคาและขอบเขตแยกก่อนใช้จริง ค่าแรงเดิมคงเป็น SAMPLE ต้องตรวจขอบเขตเช่นกัน ไม่ถือว่างานมีข้อมูลจริงครบแล้ว

ถ้าอัตราหรือพื้นที่ไม่ครบ ยอดถูกล้างเป็นขีดและปิดทางส่งออกผ่านการไม่มีผลคำนวณ ไม่ใช้ศูนย์แทนข้อมูลขาด ลบวัสดุแผงได้แต่จะหยุดคำนวณจนเลิกทำหรือคืนวัสดุครบ ข้อมูลแผงเก็บในร่างเบราว์เซอร์ร่วมกับตารางและคลัง ไม่เปลี่ยน schema ฐานข้อมูล ไม่ deploy และไม่เรียกฐานออนไลน์ระหว่างการตรวจรอบนี้

ตรวจ npm test ผ่าน 34 กรณี และ npm run build ผ่าน มีคำเตือนเดิมจาก SDK เรื่อง browser external crypto ทดสอบเบราว์เซอร์ด้วยพื้นที่ 10, ไม้อัด 2 ด้าน, ลามิเนต 2/1 ด้าน ได้พื้นที่ 20/20 และ 20/10 ตามลำดับ ใช้อัตราสมมติ 8 เมตร/ตร.ม. และกาว 2 ตร.ม./ลิตรเฉพาะตรวจพฤติกรรม เปลี่ยนเมตรขาย 3.50 → 7 วัสดุแผงไม่เปลี่ยน รีเฟรชยังเก็บค่าอยู่ ไม่ได้ตรวจ RPC ใหม่กับ InsForge


## เพิ่มสองกลุ่มและสเปกแยก — 23 ตุลาคม 2569

เจ้าของสั่งเพิ่มแผงตัวตู้และแผงหน้าบาน แต่ละกลุ่มเปิด/ปิดใช้ได้ กรอกพื้นที่ด้านเดียว จำนวนด้านบุไม้อัด/ปิดลามิเนต และเลือกไม้อัดกับลามิเนตต่างรหัสกันได้ อัตราไม้โครงและพื้นที่ครอบคลุมกาวกรอกแยกกลุ่ม ไม่มีการกำหนดอัตราจริงให้เอง

ร่างแบบหนึ่งกลุ่มเดิมย้ายค่าทั้งหมดไปแผงตัวตู้โดยคงค่าเดิม แผงหน้าบานเริ่มปิดใช้และพื้นที่ว่าง ต้องเปิดใช้และกรอกเอง ไม่ดึง 5.04 จากพื้นที่หน้าบาน VS Modular มาแทน แท็ก ราคา snapshot และคลังเดิมไม่ถูกเขียนทับ เพิ่มเฉพาะ PLY02 / LM02 ตัวอย่างสเปก B เพื่อทดลองเลือกต่างสเปก ราคา 650/1500 บาทต่อแผ่นและขนาด 2.4 × 1.2 เมตรเป็น SAMPLE เท่านั้น

เมื่อเปลี่ยนสเปก แถววัสดุที่เชื่อมพื้นที่จะปรับตามกลุ่มที่เปิดใช้ ค่าแรงและอุปกรณ์อื่นยังอยู่ ค่าเผื่อเศษของรหัสที่ยังใช้คงเดิม ประวัติลบ S001 เริ่มใหม่หลังเปลี่ยนโครงสร้างกลุ่ม ไม่คืนรายการของสเปกเก่ามาซ้อน ถ้าใช้วัสดุรหัสเดียวกันจะรวมเป็นแถวเดียวในต้นทุนและรวมกับงานอื่นในสรุปซื้อก่อนปัดจำนวนซื้อ ต่างรหัสแยกแถว ค่าเผื่อเศษในตารางวัสดุใช้ร่วมต่อรหัสจากทั้งสองกลุ่ม ไม่ใช่อัตราแยกกลุ่ม

กาวที่มี coverage ต่างกันรวมเป็นเศษส่วนที่แน่นอนก่อนส่งเข้าเครื่องคำนวณในเครื่อง เช่น 1/3 + 1/7 = 10/21 ไม่ปัดยอดรายกลุ่มก่อนรวม การแก้เมตรขายไม่เปลี่ยนปริมาณของทั้งสองกลุ่ม หากกลุ่มที่เปิดใช้กรอกไม่ครบจะไม่แสดงยอดพร้อมส่งออก ปิดใช้กลุ่มแล้วไม่นำข้อมูลที่ค้างของกลุ่มนั้นมาคำนวณ

ตรวจ npm test ผ่าน 42 กรณี และ build ผ่าน ตรวจเบราว์เซอร์พื้นที่ตัวตู้ 10/หน้าบาน 3 ตร.ม. บุสองด้าน ได้ไม้อัดและลามิเนต 20/6 ตร.ม. เมื่อเลือก PLY02/LM02 ให้หน้าบานจะแยกซื้อ 6 ตร.ม. ต่อรหัส เมื่อเลือกเหมือนตัวตู้จะรวมเป็น 26 ตร.ม. ในต้นทุนตู้ และรวมกับผนังอีก 6 เป็น 32 ตร.ม. ในสรุปซื้อ คิดซื้อ 12 แผ่นที่ขนาดตัวอย่าง 2.88 ตร.ม.ต่อแผ่น รีเฟรชแล้วค่าทั้งสองกลุ่มยังอยู่ ไม่พบ console error ระหว่างทดลอง ไม่มีการเรียก RPC หรือแก้ฐาน/ระบบออนไลน์ในรอบนี้
