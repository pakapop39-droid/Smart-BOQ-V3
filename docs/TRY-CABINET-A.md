# ทดลองตู้เตี้ยแบบ A ในฐานแยก

เปิดด้วย `npm run dev:cabinet-a` แล้วเข้า http://127.0.0.1:5188/#rates

ใช้ฐาน `data/cabinet-a-sample.sqlite` แยกจากแอปเดิมพอร์ต 5177 และ `data/smart-boq-local.sqlite` ทั้งหมดอยู่ในเครื่อง ไม่มีการเชื่อมออนไลน์ สร้าง SAMPLE ครั้งแรกเท่านั้น เปิดใหม่จะเก็บข้อมูลที่เคยทดลองไว้ ไม่คัดลอกข้อมูลจากฐานเดิม

1. คลิก **ตู้เตี้ย SAMPLE — ตัวตู้และหน้าบาน →** เพื่อเปิดตารางส่วนประกอบ
2. คลิก **ตัวตู้ →** หรือ **หน้าบาน →** เพื่อดูตารางวัสดุและค่าแรง พร้อมปริมาณและต้นทุน
3. ใช้ **ย้อนกลับ** หรือเส้นทางด้านบนกลับไปเลือกอีกส่วน ยอดรวมราคาขายต่อเมตรอยู่ด้านล่าง

ตัวอย่างมีฐานขาย 1 เมตร กำไร 40% ของราคาขาย คงสูตร Decimal และการปัดเดิม ไม่รวมท็อปหิน อัตราใช้ ราคา และสเปกทั้งหมดเป็น SAMPLE ไม่ใช่รายการก่อสร้างที่ตรวจรับแล้ว ตัวตู้และหน้าบานเป็นกลุ่มผลิตเองแบบกรอกปริมาณ ไม่ใช่สูตรวัดพื้นที่อัตโนมัติ

ตัวตู้: ไม้โครง 8 เมตร ไม้อัด 1 ตร.ม. ลามิเนต 1 ตร.ม. ค่าแรงผลิต 1 เมตร และค่าแรงติดตั้ง 1 เมตร

หน้าบาน: ไม้อัด 0.5 ตร.ม. ลามิเนต 1 ตร.ม. บานพับ 2 ตัว และค่าแรงประกอบ 1 เมตร

ต้นแบบเริ่มต้นพร้อมใช้เพื่อให้เห็นราคาขายบนตารางแรก หากต้องการทดลองแก้ตัวเลข กด **สร้างรุ่นถัดไป** ด้านบนเมื่อเปิดต้นแบบ แล้วแก้รายการในรุ่นร่าง ยอดคำนวณแสดงทันทีตามกลไกเดิม ไม่แก้รุ่นพร้อมใช้ย้อนหลัง

ผลตรวจรอบนี้: เปิดครบสามชั้นทั้งตัวตู้และหน้าบาน ย้อนกลับได้ ต้นทุนรวม 3,786.55 บาท ขาย 6,310.92 บาท/เมตร ผ่าน build และทดสอบที่เกี่ยวข้อง 10 ข้อ เปิดเซิร์ฟเวอร์ใหม่แล้วยังมีต้นแบบ 1 รายการ กลุ่ม 2 รายการ และต้นทุน 9 รายการ ไม่เพิ่มซ้ำ ตรวจข้อมูล API แอปเดิมก่อน/หลังตรงกันทั้งหมด
