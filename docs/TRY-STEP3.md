# วิธีทดลองขั้นที่ 3 — Smart BOQ V3 ในเครื่อง

เปิด http://127.0.0.1:5177/ · ใช้หน้าหลัก ไม่ใช่ /trial.html · ยังไม่เชื่อมออนไลน์

## 1. เก็บสำเนาก่อนลอง
เข้า **ฐานข้อมูล / สำรอง → ดาวน์โหลดไฟล์สำรอง JSON** เก็บไว้ก่อน ข้อมูลแอปหลักบันทึกใน SQLite เมื่อรีเฟรชหรือปิดเปิดใหม่จะยังอยู่ ไม่ต้องกดบันทึกทั้งโครงการซ้ำ

## 2. จัดคลังด้วยแท็ก
1. เข้า **คลังวัสดุ / ค่าแรง / ชุด → จัดการแท็ก** เพิ่มชื่อ เช่น งานตู้ Built-in, งานกรุผนัง และงานฝ้าตกแต่ง
2. กลับคลัง เลือกแท็บวัสดุ ค้นหา PLY แล้วติ๊กแถวที่ต้องการ ปุ่มเลือกทั้งหมดเลือกเฉพาะผลที่กำลังแสดง
3. เลือกแท็กที่จะจัดการแล้วกด **เพิ่มแท็ก** วัสดุเดิมหนึ่งรายการติดหลายแท็กได้ ไม่เกิดวัสดุซ้ำ ราคากับหน่วยไม่เปลี่ยน
4. ลองติ๊กตัวกรองสองแท็ก จะเห็นรายการที่ตรงแท็กใดแท็กหนึ่ง แล้วใช้คำค้นกรองต่อ เปลี่ยนเงื่อนไขแล้วการเลือกแถวจะถูกล้าง
5. ในจัดการแท็ก ลองเปลี่ยนชื่อ/รวมเข้าชื่ออื่น หรือลบแท็ก การลบจะแสดงจำนวนวัสดุที่เกี่ยวข้องก่อนยืนยัน แล้วใช้ **เลิกทำการลบแท็กล่าสุด** คืนได้ วัสดุไม่ถูกลบ การรวมแท็กไม่อยู่ในขอบเขตเลิกทำรอบนี้
6. รีเฟรชหน้า กลับเข้าคลัง ตรวจชื่อแท็กและรายการเดิม

ถ้ามีข้อความแท็กจากฐานรุ่นก่อน ให้กด **ตรวจแท็กเดิมก่อนย้าย** อ่านรายชื่อแล้วค่อยยืนยัน ระบบไม่เดาแท็กจากชื่อวัสดุและไม่ย้ายข้อมูล /trial.html ให้อัตโนมัติ

## 3. ทดลองต้นทุนหนึ่งโครงการ
1. กลับ **โครงการ → สร้างโครงการตัวอย่าง SAMPLE** จะได้โครงการใหม่แยกจากโครงการที่กรอกไว้
2. เปิด B01 ตรวจว่ามีตู้เตี้ย 3.50 เมตร ท็อปหิน 2.10 ตร.ม. ผนัง 6 ตร.ม. และซิงก์ 1 ชุด แยกต้นทุนกัน
3. เปิดต้นทุน **S004 ซิงก์** จดต้นทุนก่อนลบ ติ๊กก๊อกน้ำและท่อน้ำทิ้งแล้วกด **ลบต้นทุนที่เลือก** ตรวจรายการยืนยันก่อนลบ ยอดต้นทุน/ราคาขายจะเปลี่ยนทันที
4. กด **เลิกทำการลบล่าสุดของรายการนี้** ตรวจสองแถวกลับพร้อมปริมาณ ราคา ตำแหน่ง และยอดเท่าเดิม ประวัติเลิกทำยังอยู่หลังรีเฟรช แต่หากแก้ข้อมูลอื่นจนเวอร์ชันไม่ตรง ระบบจะหยุดแทนการทับข้อมูลใหม่
5. เปิด **เพิ่มต้นทุนจากคลัง** ทดลองค้นหา/กรองแท็ก ติ๊กหลายรายการแล้วเพิ่มครั้งเดียว รายการที่อยู่ในกลุ่มนั้นแล้วจะแสดง “เพิ่มแล้ว” เลือกซ้ำไม่ได้ เลือกใช้รายการเดียวกันในกลุ่มงานอื่นได้
6. หลังเพิ่ม ตรวจปริมาณ ฐานต่อหน่วยขาย/รวมทั้งรายการ และประเภทค่าแรงตามงานจริง รายการใหม่เริ่มปริมาณ 1 เผื่อเศษ 0% เป็นค่าเริ่มทดลอง ไม่ใช่สูตรรับรองหน้างาน
7. กลับรายการทำราคา → **สรุปราคา / งบซื้อ** ตรวจต้นทุน ราคาขาย และจำนวนซื้อ แล้วลองส่งออก Excel หรือพิมพ์/บันทึก PDF

ใช้เฉพาะ SAMPLE สำหรับการทดลองเพิ่ม/ลบเพื่อดูผล อย่าใช้ยอดตัวอย่างเป็นราคาเสนอจริง

## 4. ทดลอง Excel คลัง
1. ในคลังส่งออกทั้งหมด หรือเลือกบางแถวแล้วกด **ส่งออก Excel ที่เลือก**
2. เปิด Excel แก้คอลัมน์แท็กงาน โดยหนึ่งชื่ออยู่หนึ่งบรรทัดในเซลล์ เช่น งานตู้ Built-in และงานกรุผนัง ไม่แก้รหัสภายใน รุ่นข้อมูล และรหัสรายการเดิม
3. นำไฟล์กลับ อ่านตัวอย่างว่าจะแก้รายการใดและมีชื่อแท็กใหม่ใดบ้างก่อนยืนยัน ไม่มีการสร้างแท็กระหว่างดูตัวอย่าง
4. เว้นแท็กว่างในไฟล์รุ่นใหม่หมายถึงเอาแท็กออก แถวที่ไม่ได้อยู่ในไฟล์ไม่ถูกลบ ไฟล์รุ่น 1 ที่ไม่มีช่องแท็กคงแท็กเดิม
5. รุ่น 3 เก็บรายละเอียดสินค้าชุดด้วยช่อง JSON แยกต่างหาก หากยังไม่ต้องแก้ส่วนประกอบให้คงค่าที่ส่งออกไว้ ไม่ต้องพิมพ์ JSON เอง การส่งออกคลังไม่เปลี่ยนราคา snapshot ในโครงการเดิม

## 5. สำรองและตรวจร่วมกัน
ส่งออกไฟล์สำรองรุ่น 24 ตารางได้ทั้งทะเบียนแท็กและประวัติเลิกทำ การกู้คืนแทนข้อมูลทั้งฐานจะมีหน้าตรวจจำนวนตารางและไฟล์สำรองก่อนทำ ไม่ต้องกู้คืนทับงานที่ใช้อยู่เพื่อทดสอบทั่วไป รอบพัฒนาตรวจการกู้คืนบนฐานสำเนาแยก

สิ่งที่คุณต๋องช่วยตรวจ: ค้นหาวัสดุง่ายหรือไม่, จำนวนที่เลือกตรงหรือไม่, อ่านผลคำนวณทันหรือไม่, ลบ/เลิกทำเข้าใจหรือไม่ และ Excel ที่แก้แล้วกลับเข้าคลังตรงหรือไม่ การทดลองนี้ยังไม่ใช่การรับรองราคา/Index หรืออนุมัติเปิดออนไลน์
