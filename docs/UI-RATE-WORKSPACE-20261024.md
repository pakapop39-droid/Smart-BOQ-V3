# Smart BOQ V3 — หน้าคลังรายการทำราคาแบบตารางและแผงขวา
บันทึกรอบก่อนหน้า: การเปิดส่วนประกอบด้วยแท็บถูกปรับเป็น [แบบ A ตารางทีละชั้น](UI-RATE-DRILLDOWN-A-20261024.md) ตามคำยืนยันใหม่ ให้ใช้เอกสารแบบ A สำหรับหน้าปัจจุบัน

วันที่ 24 ตุลาคม 2569 · พัฒนาในเครื่องตามคำอนุมัติล่าสุด · รอคุณต๋องทดลองรับรูปแบบ

## สิ่งที่ปรับ

- หน้าคลังค้นหารหัส/ชื่อ กรองร่าง/พร้อมใช้/หยุดเลือกใช้ และแสดงจำนวนผล ใช้ตารางกระชับแทนกล่องซ้อน
- คลิกแถวหรือรหัสเพื่อเปิดต้นทุน ปุ่มแก้ข้อมูลเปิดชื่อ หน่วย และกำไรด้านขวา สถานะและคำสั่งรวมในส่วนหัว คำสั่งรองอยู่ในปุ่มเพิ่มเติม
- หน้ารายละเอียดใช้แท็บต้นทุนตรง/กลุ่มวัตถุดิบต้นทุน ตารางแสดงปริมาณใช้ ราคาต่อหน่วยใช้ และต้นทุนจากผลคำนวณเดิม แสดงข้อมูลปิดใช้/รวมในชุด/รอพิจารณาแยกชัด
- คลิกต้นทุนเปิดแผงขวา ปริมาณ ราคา ตัวหาร เผื่อเศษ และแหล่งปริมาณแก้ในแผงเดียว มีการแปลงหน่วยและคำนวณบรรทัดทันที ข้อมูลเพิ่มเติมพับได้
- ระหว่างแก้ แสดงผลร่างในตารางและแถบยอดล่าง ไม่บันทึกจนกดบันทึก เตือนบันทึก/ทิ้ง/อยู่ต่อก่อนออกเมื่อมีค่าค้าง การทิ้งร่างคืนยอดที่บันทึกไว้
- ติ๊กหลายบรรทัดต้นทุนที่คิดเงินจริงในกลุ่มที่แสดง ลบทั้งชุดหลังยืนยัน พร้อมเลิกทำคืนค่า รายละเอียดชุด และขอบเขต ใช้ธุรกรรมเดียว ไม่กระทบ snapshot โครงการ
- ช่องค้นหาเปลี่ยนแล้วล้างการเลือก เลือกทั้งหมดเฉพาะแถวที่แสดงและลบได้ ไม่เลือกแถวอ้างอิงในชุดหรือแถวปิดใช้

## ขอบเขตเทคนิคและข้อจำกัด

เพิ่มโมดูลหน้าจอ `web/local-rate-workspace.mjs` และ `web/local-rate-drawer.mjs` ใช้ฟอร์ม/การบันทึกเดิม ไม่แก้แกน `lib/live-calculator.mjs` หรือ `lib/group-quantity.mjs` ไม่เพิ่มตารางหรือย้ายข้อมูล คง 24 ตาราง

API local เพิ่ม `/rate-draft-preview` ตรวจร่างด้วย savepoint แล้ว rollback ทุกครั้ง ใช้เส้นทางตรวจต้นแบบเดิม รวมการตรวจข้อมูล/ขอบเขตเดิม ไม่ใช่การบันทึกแอบแฝง ส่วน `/rate-costs/delete` และ `/rate-costs/undo` สำหรับบรรทัดต้นทุนของต้นแบบ เก็บประวัติใน metadata บริษัทซึ่งอยู่ใน backup ทั้งฐานเดิม ไม่ใช่ Excel คลังวัสดุ

เลิกทำเป็นชุดล่าสุดของต้นแบบนั้นได้เมื่อยังเป็น DRAFT และ version ไม่เปลี่ยนหลังลบ หากมีการแก้ต้นแบบต่อ ปุ่มเลิกทำจะไม่ปรากฏเพื่อป้องกันทับข้อมูลใหม่ ไม่ใช้เลิกทำทั่วไปย้อนการลบต้นแบบหรือกลุ่มที่ยังมีลูกอ้างอิง คำสั่งเหล่านั้นคงข้อจำกัดเดิม

รอบนี้ปรับเฉพาะคลังรายการทำราคา ตารางโครงการและคลังวัสดุยังใช้รูปแบบเดิม ช่องอัตราต้นทุนในคลังยังแก้ผ่านแผงขวา ส่วนตารางแสดงผลร่างตามทัน ไม่ได้เพิ่มการแก้ราคา/หน่วยหลายรายการพร้อมกันหรือเลือกต้นแบบหลายรายการเพื่อลบ รุ่น READY ยังอ่านอย่างเดียวและต้องสร้างรุ่นถัดไปเพื่อแก้

## ผลตรวจ

- ทดสอบรวม 175/175 และ build ผ่าน เพิ่ม 7 กรณีครอบคลุมตัวกรอง การตรวจร่างโดยไม่บันทึก แปลงราคา/กำไร ข้อมูลไม่ครบ/version ขัดกัน ลบ/เลิกทำทั้งชุด backup/restore และรายละเอียดชุดไม่คิดซ้ำ
- ตรวจ UI บนสำเนา SQLite แยกที่พอร์ต 5188: RT003 ไม้โครง 8→10 เมตร ได้ 92.80→116.00 บาท; ต้นทุนทั้งรายการ 683.08→706.28 บาท; ราคาขาย 1,138.46→1,177.13 บาท โดยยังไม่บันทึกจนยืนยัน
- ตรวจการบันทึก อยู่แก้ต่อ ทิ้งค่าค้างแล้วเปลี่ยนแถว และลบสองแถวแล้วรีเฟรช/เลิกทำคืนยอดและข้อมูลทั้งชุด
- ตรวจภาพบนเดสก์ท็อปและพื้นที่ CSS ประมาณ 1367×768 (เบราว์เซอร์ซูม 80% จึงต่างจากค่าขนาดภาพ) ตารางเลื่อนแนวนอนได้ แผงเลื่อนได้และยังอ่านหน่วย/ยอดสรุป
- เทียบ state ฐานหลักก่อนทำกับหลังตรวจเท่ากัน ยังมี 4 โครงการเดิม ค่า RT003 ฐานหลักคงต้นทุน 683.08 / ขาย 1,138.46 บาท ตรวจ hash แกนคำนวณสองไฟล์ตรงเดิม หลักฐานและฐาน QA อยู่ใน artifacts/rate-workspace-20261024 ซึ่งไม่ส่งขึ้น Git

ยังไม่มีการเชื่อมออนไลน์ deploy หรือ push GitHub ผลทดสอบระบบไม่แทนเจ้าของรับรองราคาจริงหรือรับรูปแบบหน้าจอ

## วิธีทดลอง

1. เปิด http://127.0.0.1:5177/#rates แล้วรีเฟรชเพื่อโหลดหน้าจอรุ่นใหม่
2. ลองค้นหา/กรอง แล้วเปิด RT003 หรือรายการร่างของตน
3. คลิกไม้โครงหรือบรรทัดต้นทุน แก้ปริมาณด้านขวา ดูสูตรแปลงราคา ต้นทุนแถว และยอดล่าง
4. กดบันทึกเมื่อต้องการเก็บ หรือปิดแล้วเลือกทิ้งการแก้ไขเพื่อคงข้อมูลเดิม
5. หากทดลองลบ ให้ติ๊กต้นทุนที่ต้องการ ตรวจจำนวนในข้อความยืนยัน แล้วกดเลิกทำการลบก่อนแก้ต้นแบบต่อ

เมื่อเจ้าของรับรูปแบบแล้วจึงวางแผนนำชิ้นส่วนหน้าจอร่วมไปใช้กับหน้าอื่นตามลำดับ ไม่ถือว่าทุกหน้าของแอปปรับครบแล้ว
