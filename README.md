# Smart BOQ V3

> เอกสารปัจจุบันคือ [MASTER 2.0](docs/MASTER.md) · [งานตกค้าง](docs/BACKLOG.md) · [แผนเติมแท็กและเลิกทำ](docs/TAG-UNDO-PLAN.md) รอบนี้จัดเอกสารเท่านั้น ยังมีจริง 22 ตาราง แผนแท็ก 24 ตารางยังไม่ติดตั้ง ไม่เชื่อมออนไลน์

สถานะล่าสุด 23 ตุลาคม 2569: แอปทดลองในเครื่องและฐาน SQLite **22 ตารางธุรกิจ** มีคลังรายการทำราคาต่อหน่วย เลือกใช้ใน Keyplan แล้วคูณปริมาณตามแบบ พร้อมเก็บสำเนาสเปก ราคา และรุ่นไว้ในโครงการ ไม่เชื่อม InsForge และยังไม่ได้เผยแพร่ Vercel สำหรับรุ่นนี้

## เปิดใช้งานในเครื่อง

ต้องมี Node.js 22.13 ขึ้นไปพร้อม npm (ตรวจครั้งนี้ด้วย Node.js 24.19)

1. ติดตั้ง dependencies: `npm ci`
2. เปิดแอป: `npm run dev` หรือดับเบิลคลิก `start-local.cmd`
3. เปิด http://127.0.0.1:5177/ และเก็บโปรแกรมที่รันไว้ระหว่างใช้งาน

ใช้เฉพาะ 127.0.0.1 พอร์ต 5177 ไม่เปิดรับการเชื่อมต่อจากเครือข่ายอื่น ไม่ต้องตั้งค่า cloud credentials ฐานเริ่มต้นสร้างใน `data/smart-boq-local.sqlite` โดยอัตโนมัติ ข้อมูลอ้างอิงเริ่มต้นเป็น SAMPLE การสร้างโครงการตัวอย่างเลือกจากหน้าจอเอง ฐานข้อมูลของเครื่องผู้พัฒนาไม่รวมอยู่ใน GitHub

## ใช้ทดลองอะไรได้แล้ว

- โครงการ → ห้อง/พื้นที่ → Keyplan ที่กำหนดรหัสตามแบบ → รายการทำราคา → กลุ่มงาน → วัสดุและค่าแรง
- คลังวัสดุ ค่าแรง และสินค้าชุด รวมการนำเข้า–ส่งออก Excel พร้อมตรวจรายการก่อนยืนยัน
- คลังรายการทำราคาต่อหนึ่งหน่วย พร้อมกลุ่มงาน ต้นทุน ขอบเขตตรวจซ้ำ และรุ่นร่าง/พร้อมใช้
- เลือกรุ่นพร้อมใช้เข้า Keyplan แล้วกรอกปริมาณตามแบบ สำเนารายละเอียดและราคาลงโครงการ การแก้คลังรุ่นใหม่ไม่เปลี่ยนยอดโครงการเดิม
- สรุปราคาและงบซื้อ รวมการใช้วัสดุข้าม Keyplan ก่อนปัดขั้นซื้อ แยกค่าแรงออกจากวัสดุซื้อ
- แยกของที่รวมในชุด/ไม่รวม/ยังไม่ชัดเจน และตรวจเหตุผลรายการเพิ่มนอกชุด
- สำรอง–กู้คืนข้อมูลในเครื่อง และรองรับฐานเดิม 18 ตารางให้เป็น 22 ตารางโดยเก็บข้อมูลเดิม

คงสูตรเดิม: ราคาขายต่อหน่วย = ต้นทุนต่อหน่วย ÷ (1 − กำไรจากราคาขาย) ปัดราคาขายต่อหน่วยสองตำแหน่งก่อนคูณปริมาณ ไม่คิด Markup แทน Margin และไม่คูณพื้นที่แผงซ้ำ

## ข้อจำกัด

- เป็นระบบทดลองในเครื่องสำหรับบริษัทเดียว ยังไม่มี auth/RLS หรือการล็อกพร้อมใช้หลายผู้ใช้
- ข้อมูลตัวอย่างไม่ใช่ราคาจริงหรือรายการที่ตรวจรับแล้ว ยังต้องตรวจสเปก ราคา ขอบเขต และสูตรหน้างานก่อนใช้งานจริง
- ยังไม่มีระบบออกใบเสนอราคาลูกค้าสมบูรณ์ ไม่เพิ่ม VAT ส่วนลด สต็อก หรือ PO
- ไม่เปลี่ยนระบบออนไลน์เดิม และไม่มีการย้ายข้อมูลจริงหรือเผยแพร่ฐานข้อมูลลง GitHub
- หน้าต้นแบบเดิมอยู่ที่ /trial.html เอกสารรุ่นก่อนใน docs เป็นประวัติ ให้ยึด Master และคู่มือ 22 ตารางล่าสุดก่อน
- ไฟล์ .env, credentials, ฐาน SQLite, backup, node_modules, dist และหลักฐานทดสอบที่สร้างขึ้นใน artifacts ไม่รวมใน repository
